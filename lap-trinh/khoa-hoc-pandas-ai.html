Điều khiển AI xử lý dữ liệu khảo sát lớn — thay Power Query

Khóa cho team Data Analyst xử lý khảo sát nguồn nhân sự (engagement, onboarding, 360, exit interview…). Bạn không cần biết code, không cần học git — chỉ cần biết mô tả dữ liệu (context) đủ rõ để AI tự sinh code, tự check, tự update rule, và tự commit lên Git. Mọi thao tác qua prompt tiếng Việt.

P1 · Nền tảng & Context Khảo Sát

Chương 0 ★ Sự thật: AI không hiểu file của bạn — trừ khi bạn cho context

Bài học quan trọng nhất của khóa: AI chỉ giỏi khi bạn cho đủ ngữ cảnh. Với khảo sát HR, context đặc biệt phức tạp.

Hãy tưởng tượng bạn upload survey_raw.csv vào ChatGPT rồi gõ: "Tính điểm engagement trung bình". Kết quả? AI sẽ sai gần như chắc chắn — vì nó không biết:

  • Cột Q12 nghĩa là gì? (câu hỏi nào?)
  • Giá trị 1–5 là thang Likert, hay điểm thô?
  • Câu nào cần reverse-code trước khi tính tổng?
  • Điểm engagement là trung bình nhóm câu nào? (Q11–Q30? hay khác?)
  • Cột emp_id mã hóa thế nào, có trùng không?
🚫 Lỗi phổ biến #1 Tin rằng "AI thông minh, tự hiểu được". Thực tế: AI chỉ thấy các con số và tên cột vô nghĩa (Q1, Q2...). Nó sẽ đoán — và đoán sai.

Context là gì?

Context = toàn bộ thông tin AI cần để hiểu đúng dữ liệu của bạn, gồm:

Thành phầnVí dụ với khảo sát HR
Dữ liệu thôFile survey_raw.csv (50.000 dòng × 50 cột Q1–Q50)
Bản câu hỏi"Q12 = Tôi thấy ý kiến mình được lắng nghe" (Likert 1–5)
Cấu trúc bộ khảo sát"Q1–Q10: Môi trường; Q11–Q20: Lãnh đạo; Q21–Q30: Phát triển"
Quy tắc hành vi / chấm điểm"Q5, Q15 là câu reverse-code; engagement = trung bình Q11–Q30"
Chính sách missing"Bỏ trống > 30% câu → loại response khỏi phân tích"
✅ Quy luật vàng của khóa Context càng đầy đủ → AI càng đúng ngay lần đầu. 90% lỗi khi dùng AI xử lý dữ liệu là do thiếu context, không phải do AI kém.

Ví dụ: cùng 1 câu hỏi, 2 kết quả khác nhau

Prompt nghèo context (sai):

📋 Prompt NGƯỢC — kết quả sai đừng làm vậy
Tính điểm engagement trung bình theo phòng ban từ file mình đính kèm.

Prompt đủ context (đúng):

📋 Prompt ĐÚNG — đủ context template
Bạn là Data Analyst. File đính kèm: survey_raw.csv (50.000 dòng). [CONTEXT] - Cột Q1–Q50: câu hỏi khảo sát engagement, thang Likert 1–5 (1=Hoàn toàn không đồng ý, 5=Hoàn toàn đồng ý) - Nhóm chủ đề: Q1–Q10 = Môi trường; Q11–Q20 = Lãnh đạo; Q21–Q30 = Phát triển; Q31–Q40 = Đãi ngộ; Q41–Q50 = Ý nghĩa công việc - Câu reverse-code (cần đảo 6−giá trị): Q5, Q15, Q25, Q35 - Điểm engagement = trung bình Q11–Q30 (sau khi đã reverse-code) - Cột emp_id: mã nhân viên (để join với demographics) - Cột phong_ban: phòng ban [YÊU CẦU] Tính điểm engagement trung bình theo phòng ban, sắp xếp giảm dần. Loại response có >30% câu bỏ trống. Giải thích từng bước.
🎯 So sánh Cùng 1 yêu cầu, prompt thứ 2 sẽ ra kết quả đúng ngay lần đầu vì AI biết rõ: thang đo gì, câu nào reverse, nhóm nào tính engagement, chính sách missing thế nào. Đó là sức mạnh của context.

Bài thực hành 0

Mở ChatGPT/Claude/Gemini, upload 1 file CSV nhỏ của công ty (ẩn danh). Thử 2 prompt: (a) nghèo context, (b) thêm 3 dòng mô tả cột. So sánh kết quả — bạn sẽ thấy khác biệt rõ rệt.

3 thứ cần cài (nhờ AI hướng dẫn từng bước)

📋 Prompt — nhờ AI hướng dẫn cài môi trường copy-paste
Tôi là Data Analyst, máy Windows, chưa từng dùng Python. Hãy hướng dẫn tôi từng bước: 1. Cài Python 3.12+ (tick "Add to PATH") 2. Cài VS Code + 2 extension: Python + Jupyter 3. Tạo thư mục dự án, mở terminal trong VS Code 4. Cài pandas: pip install pandas openpyxl matplotlib 5. Kiểm tra: chạy lệnh import pandas as pd; print(pd.__version__) Viết rõ từng bước cho người mới, kèm lệnh chính xác.
⚠️ Đừng lo nếu không rành terminal Toàn bộ quá trình này, AI sẽ dẫn bạn từng bước. Bạn chỉ copy lệnh AI cho → dán vào terminal → Enter. Sai ở đâu, dán lỗi lại cho AI, nó sửa.
💡 Lựa chọn thay thế: Google Colab Nếu công ty không cho cài Python, dùng Google Colab (colab.research.google.com) — chạy Python ngay trong trình duyệt, miễn phí, upload CSV lên là chạy được. AI sinh code → bạn dán vào Colab.

Trước khi làm gì, bạn cần đọc được file đúng. Đây là kỹ năng đọc file cơ bản của DA — không phải làm sạch dữ liệu (việc đó thuộc quy trình rule của team thu thập).

📋 Prompt — đọc & hiểu cấu trúc 1 file CSV mới copy-paste
Bạn là Data Analyst. File đính kèm là 1 file CSV khảo sát HR mà tôi mới nhận, chưa biết cấu trúc. Hãy viết code Python (pandas) để: 1. Đọc file (thử utf-8, nếu lỗi thử các encoding phổ biến ở VN) 2. In ra: số dòng, số cột, tên tất cả cột kèm kiểu dữ liệu 3. Với mỗi cột câu hỏi: in 5 giá trị phổ biến nhất (để tôi nhận diện thang đo — Likert 1-5, 1-7, hay text?) 4. Tóm tắt bằng tiếng Việt: cấu trúc file thế nào, mỗi cột câu hỏi dùng thang đo gì — để tôi ghi vào context. Tôi sẽ chạy code, gửi kết quả lại cho bạn. (Lưu ý: việc làm sạch dữ liệu bẩn đã do team thu thập lo theo quy trình của họ — tôi chỉ cần hiểu cấu trúc để viết context.)
✅ Thói quen tốt Mỗi khi nhận file mới, chạy prompt này để hiểu cấu trúc — rồi ghi ngay vào context.md (Chương 3). Hiểu đúng thang đo & tên cột là nền cho mọi phân tích đúng.

Chương 3 ★ Context là gì & cách viết context chuẩn cho khảo sát

Chương trọng tâm. Sau chương này, bạn tự viết được 1 block context hoàn chỉnh cho bất kỳ bộ khảo sát nào của công ty.

Cấu trúc 1 block context chuẩn (5 phần)

Mọi context đều nên có đủ 5 phần sau. Bạn có thể lưu thành template, copy ra dùng mỗi lần:

📋 Template Context chuẩn cho khảo sát HR template gốc
[1. MÔ TẢ FILE] - Tên file: {survey_raw.csv} - Số dòng: {~50.000 responses} - Nguồn: {Khảo sát engagement hàng năm, thu thập qua Google Forms/LimeSurvey} [2. BẢN CÂU HỎI] - Q1: "{nội dung câu hỏi}" — thang {Likert 1-5} - Q2: ... - (hoặc đính kèm file questionnaire.md) [3. CẤU TRÚC NHÓM] - Nhóm Môi trường: Q1–Q10 - Nhóm Lãnh đạo: Q11–Q20 - ... [4. QUY TẮC CHẤM ĐIỂM / HÀNH VI] ← phần DA tự định nghĩa - Câu reverse-code (đảo giá trị): Q5, Q15, Q25 (công thức 6 - giá trị) - Điểm nhóm X = trung bình các câu trong nhóm - Điểm tổng = trung bình có trọng số (hoặc không) - Phân loại: <3.0 = "Nguy cơ", 3.0–3.8 = "Trung bình", >3.8 = "Tốt" [5. GHI CHÚ TỪ TEAM THU THẬP] ← do team thu thập cung cấp, DA chỉ ghi chú - Dữ liệu đã được làm sạch theo quy trình của team (null, duplicate, outlier đã xử lý) - Phiên bản dữ liệu: {vd: clean_v2_2025-06-30} - Liên hệ: {người phụ trách data} nếu cần rõ thêm rule làm sạch

Ví dụ context hoàn chỉnh — bộ engagement 50 câu

📋 Context thực tế — bộ engagement 50 câu ví dụ hoàn chỉnh
[MÔ TẢ FILE] File: engagement_2025_raw.csv (48.217 responses). Khảo sát engagement năm 2025, thu thập 1/6–30/6/2025. [BẢN CÂU HỎI — rút gọn] Q1: "Tôi hài lòng với môi trường làm việc" — Likert 1-5 (1=Hoàn toàn không đồng ý, 5=Hoàn toàn đồng ý) Q5: "Tôi thường xuyên phải làm thêm giờ" — REVERSE (5= hoàn toàn không đồng ý mới tốt) Q11: "Quản lý trực tiếp của tôi lắng nghe ý kiến tôi" Q15: "Tôi cân nhắc nghỉ việc trong 6 tháng tới" — REVERSE Q21–Q30: các câu về cơ hội phát triển Q41–Q50: ý nghĩa công việc [CẤU TRÚC NHÓM] - Môi trường: Q1–Q10 (điểm môi trường = avg) - Lãnh đạo: Q11–Q20 - Phát triển: Q21–Q30 - Đãi ngộ: Q31–Q40 - Ý nghĩa: Q41–Q50 - ENGAGEMENT TỔNG = avg(Q11–Q30) sau reverse-code Q15, Q25 [QUY TẮC] - Reverse: giá trị mới = 6 − giá trị cũ - Phân loại engagement: <3.0 "Nguy cơ nghỉ việc", 3.0–3.8 "Ổn", >3.8 "Gắn kết cao" [GHI CHÚ TỪ TEAM THU THẬP] - Dữ liệu đã làm sạch (null/duplicate/outlier xử lý xong theo quy trình team) - Phiên bản: clean_v2_2025-06-30. Liên hệ chị A (HR data) nếu cần rõ rule làm sạch

B. Từng version thì tốt cho vai trò gì?

Trong cùng 1 dòng model, các phiên bản thường chia theo độ "nặng" (suy luận sâu hơn = chậm hơn, đắt hơn). Chọn đúng tier giúp bạn đỡ tốn chi phí & thời gian:

DòngTier "nặng" (flagship)Tier "nhẹ" (Flash/Sonnet)Lời khuyên
ChatGPT GPT-5.2 / GPT-5.6 — suy luận & agentic mạnh (dùng bản mini/flash trong app) DA: bản flagship cho logic scoring phức tạp; bản nhỏ cho hỏi lọc/làm sạch đơn giản.
Claude Opus 5 — suy luận sâu, phân tích chiến lược Sonnet 5 — code & agentic, nhanh, rẻ (giá intro $2/$10 mỗi MTok đến 31/8/2026) DA: Sonnet 5 cho 90% việc code pandas. Opus 5 chỉ khi logic phức tạp (scoring nhiều nhóm, rule chồng nhau).

💡 Lưu ý về context window Claude (Opus/Sonnet 5) và Gemini đều hỗ trợ 1M token (Gemini mặc định; Claude 200K mặc định, 1M dạng mở rộng/tùy gói). Với bộ khảo sát 50k dòng + nhiều file mô tả, context lớn rất quan trọng — bạn dán trọn context + dữ liệu mà không bị cắt.

Chương 7 Nhờ AI scoring (tính điểm thang Likert)

Phần lõi của DA khảo sát: áp rule chấm điểm (reverse-code, tính nhóm, phân loại) lên dữ liệu đã sạch. Dữ liệu bẩn do team thu thập lo — bạn chỉ việc tính điểm đúng.
💡 Phạm vi chương này Giả sử dữ liệu đã được làm sạch theo quy trình của team thu thập (xử lý null, duplicate, outlier — đó là rule của họ). Chương này chỉ tập trung scoring: biến câu trả lời 1–5 thành điểm nhóm + điểm tổng + phân loại — đây mới là việc của DA.

Reverse-code — bẫy #1 của khảo sát

Một số câu hỏi "chiều ngược" (vd: "Tôi muốn nghỉ việc") — giá trị 5 thực ra là xấu. Trước khi tính điểm, phải đảo: giá trị mới = 6 − giá trị cũ (cho thang 1–5).

🚫 Lỗi nguy hiểm Quên reverse-code → điểm engagement bị tính ngược → nhân viên "nguy cơ nghỉ việc" lại thành "gắn kết cao". Báo cáo sai dẫn đến quyết định sai.

Các bước scoring chuẩn

  1. Reverse-code các câu chỉ định trong context (6 − giá trị, thang 1–5; 8 − giá trị, thang 1–7)
  2. Tính điểm từng nhóm chủ đề = trung bình các câu trong nhóm (Môi trường, Lãnh đạo, Phát triển, Đãi ngộ, Ý nghĩa)
  3. Tính engagement tổng theo công thức trong context (vd: avg Q11–Q30 sau reverse)
  4. Phân loại theo ngưỡng (<3.0 "Nguy cơ", 3.0–3.8 "Ổn", >3.8 "Gắn kết cao")
📋 Prompt — scoring đầy đủ (chỉ tính điểm) copy-paste

Reverse-code các câu được chỉ định (giá_trị_mới = 6 − giá_trị_cũ cho thang 1-5) 2. Tính điểm từng nhóm chủ đề (Môi trường, Lãnh đạo, Phát triển, Đãi ngộ, Ý nghĩa) = trung bình các câu trong nhóm 3. Chương 13 Case study: báo cáo engagement quý — full loop

Walkthrough 1 báo cáo thật từ đầu đến cuối: nhận file raw → context → prompt từng bước → báo cáo → commit. Đây là tổng hợp toàn khóa.

Kịch bản

Đầu quý 4/2025, HR gửi bạn file engagement_q3_2025.csv (52.000 responses). Quản lý yêu cầu báo cáo engagement theo phòng ban + nhóm chủ đề, nộp trong 2 ngày. Cách làm cũ (Power Query): mất 1.5 ngày. Cách mới (AI + Python): 2 giờ.

Bước 1 — Chọn AI & đọc context (10 phút)

Dùng hướng dẫn Chương 4. Với 4 file (raw + questionnaire + structure + behavior) → chọn Gemini 3.6 Flash (context 1M) cho tổng quan; Claude Sonnet 5 khi bắt đầu viết code production. Chuẩn bị context theo Chương 3.

Bước 2 — Merge demographics (20 phút)

Dùng prompt Chương 6, LEFT JOIN với demographics.csv. 89 nhân viên thiếu thông tin phòng ban → báo HR bổ sung.

Bước 3 — Scoring (30 phút)

Dùng prompt Chương 7. Reverse-code Q5, Q15, Q25, Q35. Tính điểm 5 nhóm + engagement tổng. Verify 5 dòng trước/sau reverse.

Bước 4 — Báo cáo (30 phút)

Dùng prompt Chương 8. Xuất Excel nhiều sheet + heatmap. Viết insight tiếng Việt.

Bước 5 — Build pipeline (25 phút)

Dùng prompt Chương 11. Gom thành run_report.py. Lần sau mỗi quý chạy 1 lệnh.

Bước 6 — Commit lên Git (10 phút)

Dùng prompt Chương 12. Commit code + context (đã ẩn danh). Đồng nghiệp có thể xem/lại dùng.

🎯 Kết quả 2 giờ thay vì 1.5 ngày. Báo cáo đầy đủ hơn cũ (có heatmap, insight). Code tái dùng cho quý sau. Đây là mục tiêu của khóa — tự chủ điều khiển AI end-to-end.
📋 Prompt — kickoff 1 dự án báo cáo mới meta-prompt
Bạn là trợ lý Data Analyst. Tôi nhận báo cáo engagement quý mới (dữ liệu đã được team thu thập làm sạch). Hãy dẫn tôi qua từng bước (merge → score → báo cáo → pipeline → commit), ở mỗi bước: 1. Cho tôi prompt chính xác để làm bước đó 2. Giải thích tôi cần chuẩn bị gì (file nào, context gì) 3. Sau khi tôi làm xong, tôi báo kết quả, bạn sang bước kế Tôi mới học quy trình này, hãy kiên nhẫn và rõ ràng. Bắt đầu từ bước merge dữ liệu.

Chương 14 Thư viện Prompt (copy-paste, phân loại)

Tổng hợp các prompt xuyên khóa, phân loại theo mục đích. Copy ra dùng ngay.

A. Prompt khám & đọc dữ liệu

📋 Khám phá file CSV lạ copy-paste
Bạn là Data Analyst. File đính kèm là CSV khảo sát HR mới. Viết code pandas để: đọc file (thử utf-8 rồi các encoding VN), in số dòng/cột/kiểu, với mỗi cột in null% + 5 giá trị phổ biến, check duplicate theo emp_id. Tóm tắt tiếng Việt các vấn đề cần làm sạch.

B. Prompt làm sạch & scoring

📋 Reverse-code + scoring đầy đủ copy-paste
Bạn là Data Analyst. File + context đính kèm. Thực hiện đúng thứ tự: (1) reverse-code các câu chỉ định (6−giá trị cho thang 1-5), (2) giá trị ngoài thang → null, (3) loại response >30% null, (4) tính điểm từng nhóm chủ đề, (5) tính engagement tổng theo context, (6) phân loại theo ngưỡng. In 5 dòng trước/sau reverse để verify. Xuất scored_data.csv.

C. Prompt phân tích & báo cáo

📋 Báo cáo theo phòng ban + insight copy-paste
Bạn là Data Analyst. File scored_data.csv đính kèm. Tạo báo cáo: bảng engagement trung bình theo phòng ban × 5 nhóm chủ đề, đánh dấu ô <3.0, top 3 phòng thấp/cao, nhóm chủ đề yếu nhất toàn công ty, heatmap PNG, xuất Excel nhiều sheet. Viết 3 insight tiếng Việt ở sheet đầu.

D. Prompt vòng đời code

📋 Review code cũ + update rule copy-paste
Bạn là Senior DA. Review code sau (đính kèm context), chỉ ra: lỗi logic (quên reverse? missing sai?), hiệu năng, edge case. Đưa code đã sửa. NẾU có rule mới {mô tả}, update context + code tương ứng, đánh dấu "# MỚI". Giải thích tiếng Việt.

E. Prompt Git (nhờ AI hết)

📋 Commit + push (không học git) copy-paste
Tôi là DA, chưa từng học git. Tôi sửa xong {mô tả thay đổi}. Hãy cho đúng các lệnh để commit + push lên {repo URL}, kèm commit message tiếng Việt rõ ràng. Mỗi lệnh kèm 1 câu giải thích. Tôi copy dán terminal. Nếu lỗi tôi dán lại.
