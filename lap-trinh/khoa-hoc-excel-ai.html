Làm chủ AI + Python + CSV cho Data Analyst (dữ liệu lớn)

Khóa học dành cho người xử lý dữ liệu — kế toán, phân tích kinh doanh, vận hành, sale. Nội dung trung tâm: thay vì nhớ hàng chục công thức Excel, bạn mô tả yêu cầu bằng tiếng Việt → AI viết code Python (pandas) chạy trên file CSV của bạn → trả kết quả, insight, biểu đồ. Không cần biết code. Phần Excel truyền thống (VLOOKUP, SUMIFS, Pivot...) vẫn có ở phần sau làm tham khảo khi bạn phải dùng Excel.

📖 17 chương 🐍 P1 trung tâm: AI+Python+CSV 📋 30+ prompt chuẩn 📊 50+ công thức
🎯 Cốt lõi khóa học (đọc kỹ) Bạn không cần học lập trình. Bạn học cách mô tả yêu cầu dữ liệu (prompt) → AI viết code Python (pandas) → bạn copy vào Google Colab / ChatGPT Code Interpreter hoặc để AI tự chạy. P1 (6 chương đầu) là nội dung trung tâm; P2 (Excel truyền thống) là tham khảo phụ trợ.
Cần chuẩn bị gì? Một tài khoản AI (ChatGPT Plus để upload CSV tự chạy, hoặc bản miễn phí + Google Colab). File CSV dữ liệu của bạn để thực hành. Không cần cài Python, không cần biết code. Excel chỉ cần khi tới phần P2 (tham khảo).
P1 · TRUNG TÂM: AI THAO TÁC TRÊN DATA BẰNG PROMPT (1 LUỒNG THUẦN PROMPT)

Chương 0 1 luồng duy nhất: Upload file → Gõ câu hỏi → Nhận kết quả

Bạn không cần biết code, không cần biết tên cột, không cần gửi header. Chỉ upload file CSV/Excel vào AI (ChatGPT, Claude, Gemini) rồi gõ câu hỏi bằng tiếng Việt — AI tự đọc hiểu cấu trúc, tự viết code, tự chạy, trả kết quả. Đây là toàn bộ luồng trung tâm của khóa, nằm gọn trong 1 chương.

1. Luồng 3 bước — chỉ vậy thôi

🎯 Luồng trung tâm (đọc 3 lần)
  1. Upload file (CSV/Excel) trực tiếp vào ChatGPT / Claude / Gemini — bằng nút 📎 đính kèm, giống gửi file cho đồng nghiệp.
  2. Gõ câu hỏi bằng tiếng Việt — viết tự nhiên như nhờ đồng nghiệp: "tính tổng doanh thu theo thành phố", "top 5 sản phẩm bán chạy nhất", "so sánh tháng này với tháng trước".
  3. Nhận kết quả — AI tự đọc hết cột, tự viết code, tự chạy trên file bạn upload, trả về bảng + biểu đồ + giải thích.
❌ Bạn KHÔNG cần làm những việc sau
  • ❌ Liệt kê tên cột / gửi header cho AI — AI tự đọc từ file.
  • ❌ Mô tả kiểu dữ liệu mỗi cột — AI tự nhận diện.
  • ❌ Viết hoặc hiểu code Python/pandas — AI tự viết & tự chạy (nếu dùng ChatGPT Plus / Claude).
  • ❌ Copy code sang Google Colab/Jupyter — trừ khi bạn muốn (xem mục "không có Plus" bên dưới).

3. Câu hỏi mẫu — gõ y hệt, thay yêu cầu

Dưới đây là các câu hỏi bạn gõ trực tiếp vào chat (sau khi upload file). Không cần sửa gì khác — chỉ thay phần yêu cầu theo ý bạn. Bấm sao chép, dán, gửi.

📋 Câu hỏi mẫu — Khám phá dữ liệu (gõ sau khi upload) copy-paste
File tôi vừa gửi là dữ liệu bán hàng. Hãy đọc file và cho tôi biết: - Có bao nhiêu dòng, cột nào - 5 dòng đầu trông thế nào - Khoảng thời gian dữ liệu bao phủ - Có cột nào bị thiếu giá trị không
📋 Câu hỏi mẫu — Tổng hợp theo nhóm (thay Pivot/SUMIFS) copy-paste
Với file tôi vừa gửi: Tính tổng doanh thu theo từng thành phố, sắp xếp giảm dần. Đưa kết quả dạng bảng + biểu đồ cột top 10.
📋 Câu hỏi mẫu — Lọc theo điều kiện copy-paste
Với file tôi vừa gửi: Lọc ra các đơn hàng ở Hà Nội có doanh thu trên 1 tỷ. Sắp xếp giảm dần theo doanh thu, chỉ lấy 20 đơn lớn nhất.
📋 Câu hỏi mẫu — So sánh theo thời gian copy-paste
Với file tôi vừa gửi: So sánh doanh thu tháng gần nhất với tháng trước đó. Tính % tăng/giảm. Cho biết 3 sản phẩm giảm nhiều nhất.
📋 Câu hỏi mẫu — Phân tích insight đầy đủ copy-paste
Với file tôi vừa gửi: Phân tích và đưa ra: 1. 3 insight quan trọng nhất (kèm số liệu) 2. Top 3 sản phẩm có doanh thu giảm mạnh nhất 3. Bất thường nào cần lưu ý 4. 2 đề xuất hành động kinh doanh cụ thể Viết rõ ràng, có cấu trúc, bằng tiếng Việt.

4. Mẹo gõ câu hỏi để AI hiểu đúng (prompt tốt = kết quả tốt)

Vì bạn không cần gửi header, AI tự đọc cột — nên việc duy nhất cần làm tốt là mô tả yêu cầu rõ. Bảng so sánh prompt yếu ↔ mạnh:

Prompt yếu (kết quả sai/chung chung)Prompt mạnh (kết quả đúng)
"phân tích dữ liệu""tính tổng doanh thu theo thành phố, top 10, kèm biểu đồ"
"cho xem bán chạy""top 5 sản phẩm theo tổng doanh thu, sắp xếp giảm dần"
"tháng này thế nào""so sánh doanh thu tháng 6 vs tháng 5, tính % thay đổi"
"tìm khách VIP""phân loại khách hàng thành A/B/C theo tổng doanh thu, đề xuất ngưỡng"
💡 Công thức câu hỏi mạnh [đối tượng] + [hành động] + [nhóm] + [điều kiện] + [định dạng]. Ví dụ: "tính [tổng doanh thu] [theo thành phố], [chỉ lấy top 10], [sắp xếp giảm dần], [kèm biểu đồ cột]". Càng cụ thể, AI càng đúng.
⚠️ Khi AI hỏi lại "cột nào?" Đôi khi AI hỏi "doanh thu là cột nào?". Đừng hoảng — chỉ trả lời ngắn: "doanh thu = cột doanhthu". Hoặc tốt hơn: sửa lại câu hỏi cho rõ ngay từ đầu ("doanh thu = cột doanhthu"). AI có Plus sẽ tự đọc file nên hiếm khi hỏi.

5. Không có ChatGPT Plus / Claude — làm sao?

Nếu bạn dùng bản miễn phí (không upload file / không tự chạy code), vẫn dùng được luồng này với 1 bước thêm:

  1. Upload file hoặc dán 5-10 dòng đầu (copy từ Excel, dán vào chat — AI đủ hiểu cấu trúc).
  2. Gõ câu hỏi như bình thường.
  3. AI viết code cho bạn (không tự chạy) → bạn copy code dán vào Google Colab (colab.research.google.com — miễn phí, không cài đặt) → upload file → chạy 1 nút. Kết quả hiện ra.
💡 Google Colab = 30 giây setup Vào colab.research.google.com → New notebook → dán code AI cho → upload file (icon thư mục bên trái) → Shift+Enter để chạy. Miễn phí, không cài Python. Chỉ làm 1 lần, lần sau copy code mới vào là chạy được.

6. Khi nào cần Excel truyền thống (P2)?

Luồng AI trên giải quyết 90% công việc DA. Bạn chỉ cần Excel truyền thống (công thức, Pivot) khi:

  • Sếp yêu cầu file Excel có công thức sống (đổi số tự tính lại).
  • Không được phép upload dữ liệu ra AI (bảo mật) — và không có AI enterprise.
  • Cần báo cáo Excel định dạng đẹp, có template cố định.

Các trường hợp còn lại — phân tích, tổng hợp, insight, biểu đồ, làm sạch — dùng luồng AI ở chương này nhanh hơn rất nhiều. Phần P2 (Excel truyền thống) ở sau là tài liệu tham khảo cho 3 trường hợp đặc biệt trên.

🎯 Tóm lại Upload → Gõ câu hỏi → Nhận kết quả. 3 bước. Không code, không header, không công thức. Đó là toàn bộ luồng trung tâm. Các chương sau (C1-C5) là bộ sưu tập câu hỏi mẫu theo từng tình huống — bạn copy, dán, thay yêu cầu.

Chương 1 Bộ sưu tập câu hỏi: Lọc & tìm kiếm

Các câu hỏi mẫu để lọc/tìm dữ liệu — upload file rồi gõ y hệt, thay yêu cầu.
Cách dùng Upload file vào AI → sao chép 1 câu hỏi bên dưới → dán → gửi. AI tự đọc cột, tự làm. Không cần sửa gì khác ngoài phần yêu cầu.
📋 Lọc theo 1 điều kiện
Với file tôi vừa gửi: Cho tôi tất cả đơn hàng ở Hà Nội.
📋 Lọc nhiều điều kiện
Với file tôi vừa gửi: Lọc đơn hàng ở Hà Nội HOẶC Đà Nẵng, có doanh thu trên 1 tỷ, trong tháng 6. Sắp xếp giảm dần theo doanh thu, top 20.
📋 Tìm top/bottom
Với file tôi vừa gửi: Top 10 khách hàng có tổng doanh thu cao nhất. Kèm cột tổng doanh thu và số đơn của từng người.
📋 Tìm giá trị bất thường (outlier)
Với file tôi vừa gửi: Tìm các đơn hàng có doanh thu bất thường (cao/h thấp hơn hầu hết). Giải thích vì sao bất thường.

Chương 2 Bộ sưu tập câu hỏi: Tổng hợp & nhóm

Tính tổng/đếm/trung bình theo nhóm — thay Pivot Table & SUMIFS.
📋 Tổng hợp theo 1 nhóm
Với file tôi vừa gửi: Tính tổng doanh thu theo từng thành phố, sắp xếp giảm dần. Kèm biểu đồ cột top 10.
📋 Tổng hợp nhiều chỉ số + nhiều nhóm
Với file tôi vừa gửi: Tính theo từng thành phố × sản phẩm: - Tổng doanh thu - Số đơn hàng - Doanh thu trung bình 1 đơn - % đóng góp vào tổng Sắp xếp theo tổng doanh thu giảm dần.
📋 Phân loại A/B/C (ABC analysis)
Với file tôi vừa gửi: Phân loại khách hàng thành A (top 20% doanh thu), B (20-50%), C (còn lại). Đưa số lượng + tổng doanh thu mỗi nhóm + đề xuất hành động cho từng nhóm.
📋 Bảng chéo (2 chiều, thay Pivot 2 cấp)
Với file tôi vừa gửi: Tạo bảng chéo: dòng = thành phố, cột = tháng, giá trị = tổng doanh thu. Kèm dòng tổng cuối và cột tổng cuối.

Chương 3 Bộ sưu tập câu hỏi: Nối 2 file (thay VLOOKUP)

Upload 2 file → gõ câu hỏi → AI tự nối & phân tích.
Cách dùng Upload cả 2 file vào cùng 1 chat (dùng nút 📎 nhiều lần). AI tự nhận diện cột chung & nối.
📋 Nối 2 file & tính toán
Tôi vừa gửi 2 file: file bán hàng và file khách hàng. Nối 2 file theo mã khách hàng (nếu có), rồi: Tính tổng doanh thu theo thành phố (lấy từ file khách hàng). Top 5 thành phố cao nhất, kèm biểu đồ.
📋 Nối & tìm khách chưa mua
Tôi vừa gửi 2 file: file khách hàng và file đơn hàng. Cho tôi danh sách khách hàng CHƯA có đơn hàng nào (chỉ có trong file khách, không có trong file đơn).
📋 Gộp nhiều file giống nhau
Tôi vừa gửi nhiều file (bán hàng từng tháng). Gộp tất cả lại thành 1 bảng, thêm cột "tháng" từ tên file. Sau đó tính tổng doanh thu theo tháng, vẽ biểu đồ đường xu hướng.

Chương 4 Bộ sưu tập câu hỏi: Thời gian & xu hướng

So sánh theo thời gian, tìm xu hướng, dự báo — bằng câu hỏi tiếng Việt.
📋 So sánh kỳ (MoM, YoY)
Với file tôi vừa gửi: So sánh doanh thu tháng gần nhất với: - Tháng trước đó (% thay đổi) - Cùng tháng năm trước (% thay đổi) Đưa bảng so sánh + nhận xét ngắn.
📋 Xu hướng & mùa vụ
Với file tôi vừa gửi: Phân tích xu hướng doanh thu theo tháng. Có mùa vụ không? Vẽ biểu đồ đường. Chỉ ra tháng cao điểm & thấp điểm.
📋 Dự báo đơn giản
Với file tôi vừa gửi: Dựa vào xu hướng, dự báo doanh thu 3 tháng tới. Nêu rõ giả định. Vẽ biểu đồ gồm lịch sử + dự báo.
📋 Lũy kế từ đầu năm (YTD)
Với file tôi vừa gửi: Tính doanh thu lũy kế từ đầu năm đến hiện tại, theo từng tháng. Vẽ biểu đồ cột lũy kế.

Chương 5 Bộ sưu tập câu hỏi: Làm sạch & biểu đồ & báo cáo

Làm sạch dữ liệu, vẽ biểu đồ, viết báo cáo — toàn bằng câu hỏi.
📋 Làm sạch dữ liệu
Với file tôi vừa gửi: Kiểm tra và làm sạch: - Xóa dòng trùng lặp - Điền giá trị thiếu (deating hợp lý cho từng cột) - Chuẩn hóa текст (xóa space thừa, viết hoa chữ đầu tên) Cho tôi file kết quả đã sạch (download).
📋 Dashboard biểu đồ
Với file tôi vừa gửi: Vẽ 4 biểu đồ trên cùng 1 hình: 1. Biểu đồ cột top 10 thành phố doanh thu 2. Biểu đồ đường doanh thu theo tháng 3. Biểu đồ tròn cơ cấu sản phẩm 4. Biểu đồ cột ngang top 5 khách hàng Có tiêu đề tiếng Việt, lưu PNG.
📋 Viết báo cáo cho sếp
Với file tôi vừa gửi: Viết báo cáo tóm tắt cho sếp (không chuyên gia kỹ thuật), gồm: 1. Tổng quan (1 đoạn) 2. 3 điểm nổi bật (kèm số liệu) 3. 2 vấn đề cần chú ý 4. 2 đề xuất hành động Viết ngắn gọn, dễ hiểu, tiếng Việt. Dùng kết quả phân tích từ file.
📋 Xuất file kết quả
Với file tôi vừa gửi: Tính tổng doanh thu theo thành phố × sản phẩm. Xuất kết quả ra file Excel (hoặc CSV) để tôi download.
🎯 Tóm tắt P1 Toàn bộ P1 chỉ là: upload file → gõ câu hỏi tiếng Việt → nhận kết quả. 5 chương trên là bộ sưu tập câu hỏi mẫu theo tình huống. Bạn copy, dán, thay yêu cầu. Không code, không header, không công thức. Phần P2 (Excel truyền thống) bên dưới chỉ dùng khi sếp bắt nộ file Excel có công thức, hoặc không được upload dữ liệu ra AI.
P2 · EXCEL TRUYỀN THỐNG (CÔNG THỨC — THAM KHẢO)

Chương 6 Tổng quan: AI + Excel cho Data Analyst

Vì sao AI thay đổi cách bạn làm Excel — và cách nghĩ về dữ liệu. (Phần Excel truyền thống — tham khảo khi không dùng Python.)

1. Vấn đề: Excel "đau" ở đâu?

Chương 7 Làm chủ dữ liệu lớn trong Excel

Khi Excel vượt quá 100k dòng: quy tắc để không bị treo, các công cụ xử lý dữ liệu lớn.

1. Giới hạn của Excel "thông thường"

Excel có giới hạn: 1.048.576 dòng × 16.384 cột. Nhưng thực tế, khi file > 100MB hoặc công thức volatile (INDIRECT, OFFSET, TODAY) xuất hiện nhiều, Excel bắt đầu chậm/không phản hồi. Nguyên tắc sống còn khi dữ liệu lớn:

NênKhông nên
Dùng Table (Ctrl+T) thay range thườngRange tĩnh A1:D100000
Dùng Power Query xử lý trước khi nạpCopy-paste nguyên file CSV vào
Dùng Pivot Table tổng hợpĐể nguyên hàng trăm nghìn dòng rồi filter
Công thức tham chiếu cột Table [@doanhthu]Công thức volatile (OFFSET, INDIRECT) hàng nghìn dòng
🚫 Công thức "kẻ thù" hiệu năng INDIRECT, OFFSET, TODAY(), NOW(), RAND() là volatile — tính lại mỗi khi Excel thay đổi gì đó. Trên dữ liệu lớn = chậm rất nhiều. Hạn chế tối đa.

2. Chuyển range thành Table

Table (Ctrl+T) là bước chuyển đổi quan trọng nhất cho dữ liệu lớn. Lợi ích: tự động mở rộng khi thêm dòng, công thức dùng tên cột ([@doanhthu]) dễ đọc, định dạng tự động, filter/sort tích hợp.

[Cách 2] Insert → Table

Sau khi thành Table, đặt tên (Table Design → Table Name):
Tên bảng: tblBanHang

Tham chiếu trong công thức (rất dễ đọc):

Chương 8 VLOOKUP / XLOOKUP / INDEX-MATCH

3. Lookup

Lookup là nhóm công thức "sinh tồn" của DA. Nó giúp bạn tìm một giá trị trong bảng này rồi lấy thông tin tương ứng từ bảng khác. Ví dụ: từ mã khách hàng, lấy tên + số điện thoại từ bảng khách hàng.

Công thứcCú phápDùng khi
VLOOKUP=VLOOKUP(giá_trị_tìm; bảng; cột_thứ; 0)Tra cứu cơ bản (lỗi thời nhưng phổ biến)
XLOOKUP=XLOOKUP(tìm; cột_tìm; cột_lấy; "không thấy")M365 — ưu tiên dùng cái này
INDEX + MATCH=INDEX(cột_lấy; MATCH(tìm; cột_tìm; 0))Phiên bản cũ, mạnh hơn VLOOKUP (tra 2 chiều)
excel●
[Bài toán] Từ mã KH (cột A), lấy tên KH từ bảng dmkhachhang

-- VLOOKUP (cột phải ở bên phải cột tìm)
=VLOOKUP(A2; dmkhachhang!A:C; 2; 0)    # 2 = cột tên (B)

-- XLOOKUP (M365, không quan tâm thứ tự cột)
=XLOOKUP(A2; dmkhachhang!A:A; dmkhachhang!B:B; "Không có")

-- INDEX + MATCH (mạnh, tra trái/phải đều được)
=INDEX(dmkhachhang!B:B; MATCH(A2; dmkhachhang!A:A; 0))
⚠️ Lỗi #N/A #N/A = không tìm thấy giá trị. Nguyên nhân: giá trị không có thật, hoặc sai kiểu (text vs number — "123" ≠ 123). Bọc trong IFERROR(VLOOKUP(...); "Không có") để hiển thị gọn.
✅ Khi nào dùng cái nào? Có M365 → luôn XLOOKUP (đơn giản, tra trái phải, có thông báo lỗi). Cũ hơn → INDEX+MATCH (mạnh hơn VLOOKUP). VLOOKUP chỉ dùng khi kế thừa file cũ.
📋 Prompt — AI viết công thức lookup copy-paste
Bạn là chuyên gia Excel. Viết công thức: - Tìm giá trị ô [A2] trong cột [Mã KH] của sheet [dmkhachhang] - Trả về [Tên KH] từ cột tương ứng - Nếu không thấy, hiện "Chưa có" Yêu cầu: dùng XLOOKUP (hoặc INDEX+MATCH nếu không có M365). Giải thích ngắn từng tham số.

Chương 9 SUMIFS / COUNTIFS & công thức điều kiện

4. Aggregate có điều kiện

Nhóm này dùng mỗi ngày: tính tổng/đếm/trung bình theo nhiều điều kiện. Ví dụ: tổng doanh thu của thành phố HN, tháng 6, sản phẩm A.

Công thứcCú phápVí dụ
SUMIFS=SUMIFS(cột_tính; cột_đk1; giá_trị1; cột_đk2; giá_trị2; ...)Tổng DT theo nhiều điều kiện
COUNTIFS=COUNTIFS(cột_đk1; giá_trị1; ...)Đếm theo nhiều điều kiện
AVERAGEIFS=AVERAGEIFS(cột_tính; ...)Trung bình theo điều kiện
SUMPRODUCT=SUMPRODUCT((đk1)*(đk2)*(cột_tính))Tính theo điều kiện phức tạp (hoặc có "hoặc")
excel●
[Bài toán] Tổng doanh thu: city="HN", tháng=6, sản phẩm="A"

=SUMIFS(tblBanHang[doanhthu];
        tblBanHang[city]; "HN";
        tblBanHang[thang]; 6;
        tblBanHang[sanpham]; "A")

[Đếm] Đơn hàng city="HN", DT>1000000
=COUNTIFS(tblBanHang[city]; "HN"; tblBanHang[doanhthu]; ">1000000")

[SUMPRODUCT — đếm có "HOẶC"] Đếm city="HN" HOẶC "ĐN"
=SUMPRODUCT(((tblBanHang[city]="HN")+(tblBanHang[city]="ĐN"))*1)
⚠️ Lỗi thường gặp SUMIFS (1) Sai thứ tự: SUMIFS đặt cột tính tổng trước, khác SUMIF cũ. (2) Quên ngoặc kép quanh điều kiện text/số: ">1000000". (3) Range không cùng kích thước.
📋 Prompt — AI viết SUMIFS nhiều điều kiện copy-paste
Bạn là chuyên gia Excel. Viết công thức SUMIFS: - Bảng: [tblBanHang] - Cột tính tổng: [doanhthu] - Điều kiện 1: [city] = "HN" - Điều kiện 2: [thang] = 6 - Điều kiện 3: [sanpham] = "A" Chỉ đưa công thức + giải thích ngắn. Nếu có cách dùng SUMPRODUCT cho điều kiện "HOẶC", đề xuất kèm.

Chương 12 Power Query & Power Pivot (DAX)

Vũ khí xử lý dữ liệu lớn & nhiều nguồn — chạy nhanh gấp nhiều lần Excel thường.

1. Power Query: ETL trong Excel

Power Query (Get & Transform) là công cụ trích xuất - biến đổi - nạp dữ liệu. Bạn thao tác bằng giao diện (không code), mỗi bước được ghi lại thành query có thể chạy lại. Lý tưởng cho: gộp nhiều file CSV, làm sạch lặp lại, join bảng lớn.

các bước điển hình●
[Power Query — workflow]
Data → Get Data → From File / From Folder (gộp nhiều file)
→ Power Query Editor mở ra:
   - Remove Columns: xóa cột không cần
   - Filter Rows: lọc
   - Split Column: tách cột theo dấu
   - Merge Queries: JOIN bảng
   - Group By: GROUP BY
   - Replace Values: SUBSTITUTE hàng loạt
→ Close & Load → nạp kết quả về Excel
→ Lần sau: chỉ cần Refresh → chạy lại toàn bộ!
🎯 Tại sao Power Query thay copy-paste? (1) Tự động: lần sau chỉ Refresh, không làm lại. (2) Xử lý hàng triệu dòng mượt (engine mạnh hơn Excel). (3) Có "audit trail" — mỗi bước ghi lại, dễ debug. (4) AI (Chương 9) sinh code M (ngôn ngữ Power Query) cho bạn.

2. Power Pivot & DAX

Power Pivot mở rộng Pivot Table: xử lý nhiều bảng + measure mạnh bằng ngôn ngữ DAX. Vượt giới hạn Pivot thường khi cần: quan hệ nhiều bảng, tính toán thời gian (YTD, so sánh kỳ), measure phức tạp.

DAX MeasureÝ nghĩa
SUMX(bang; [sl]*[gia])Tổng có tính toán trên từng dòng
TOTALYTD(SUM([dt]); [ngay])Lũy kế từ đầu năm
CALCULATE(SUM([dt]); [city]="HN")Tổng có điều kiện phức tạp
SAMEPERIODLASTYEAR([ngay])So sánh cùng kỳ năm trước
⚠️ DAX khó hơn công thức thường DAX có khái niệm "context" (ngữ cảnh dòng vs filter) phức tạp. Đây là chỗ AI cực kỳ hữu ích — mô tả yêu cầu, AI viết DAX đúng (Chương 8 & 9).

⚠️ Quy tắc dữ liệu mẫu Khi dán bảng vào AI, không cần dán toàn bộ — dán 50-100 dòng đại diện (hoặc bảng đã tổng hợp qua Pivot). AI đủ hiểu cấu trúc. Tránh dán 10.000 dòng (chậm, đắt, vượt giới hạn).

Chương 15 AI + VBA: tự động hóa & macro

Không cần biết lập trình — mô tả yêu cầu, AI sinh code VBA, bạn copy vào Excel.

1. Macro & VBA cơ bản

Macro ghi lại thao tác để chạy lại. VBA là ngôn ngữ lập trình Excel — mạnh hơn macro rất nhiều nhưng cần code. Tin vui: AI viết VBA cho bạn. Bạn chỉ cần biết cách chạy.

cách chạy VBA●
[Bật Developer tab] File → Options → Customize Ribbon → đánh dấu Developer
[Mở VBA] Alt + F11 → Insert → Module → dán code
[Chạy] F5 hoặc Developer → Macros → Run

2. Prompt AI sinh VBA

📋 Prompt — sinh macro VBA copy-paste
Bạn là chuyên gia Excel VBA. Viết macro: [YÊU CẦU]: Xóa tất cả dòng trống trong sheet "Data", sau đó lưu file thành "clean.xlsx" vào thư mục C:\Reports, kèm timestamp. Yêu cầu: - Code có comment tiếng Việt - Có thông báo khi xong (MsgBox) - Xử lý lỗi (nếu không có dòng trống thì vẫn báo OK) - Giải thích ngắn cách chạy (Alt+F11 → Module → dán → F5)
🚫 An toàn VBA VBA có thể xóa/sửa file. Luôn save bản sao trước khi chạy macro lạ. AI sinh code có thể sai — đọc comment, chạy trên file test trước khi chạy thật.

Chương 16 Workflow end-to-end: AI trợ lý Excel

Quy trình 5 bước biến AI thành trợ lý Excel cá nhân — từ file thô đến báo cáo.

1. Workflow chuẩn DA + AI

  1. Nhận dữ liệu thô (CSV/ERP/export) → nạp vào Excel qua Power Query.
  2. Dán cấu trúc cho AI (5 dòng đầu) → AI gợi ý bước làm sạch (tách cột, sửa kiểu).
  3. AI viết công thức cho cột tính toán (lookup, điều kiện, gom nhóm).
  4. Pivot + Pivot Chart tổng hợp → dán bảng tổng hợp vào AI nhận insight.
  5. AI tóm tắt & đề xuất → viết báo cáo cho sếp / quyết định kinh doanh.
🎯 Quy tắc 80/20 80% thời gian DA cũ ở làm sạch + viết công thức. AI rút xuống 20% — bạn tập trung 80% thời gian còn lại vào insight & quyết định (phần có giá trị thực).

2. Prompt "meta" — AI hướng dẫn cả workflow

📋 Prompt — AI tư vấn workflow copy-paste
Bạn là cố vấn Data Analyst. Tôi có file Excel: [MÔ TẢ]: {vd: doanh số bán hàng, 200k dòng, các cột: ngay, city, sanpham, sl, dt, khachhang} Lập kế hoạch phân tích end-to-end: 1. Các bước làm sạch cần làm (Power Query hay công thức?) 2. Cột tính toán nên thêm (kèm công thức gợi ý) 3. Cấu trúc Pivot Table nên tạo (hàng/cột/values) 4. 5 câu hỏi insight nên hỏi (kèm prompt cho từng câu) 5. Định dạng báo cáo cuối cho sếp Viết rõ ràng, theo trình tự, tiếng Việt.

3. Tổng kết khóa

✅ Bạn đã học (1) Nền tảng dữ liệu lớn trong Excel (Table, Power Query). (2) Công thức cốt lõi: XLOOKUP, SUMIFS, INDEX-MATCH, text/date. (3) Pivot + Power Pivot/DAX. (4) Thư viện prompt để AI viết công thức, sửa lỗi, phân tích, sinh VBA. Giờ AI là trợ lý Excel của bạn — mô tả bằng tiếng Việt, nhận kết quả.
🎯 Bước tiếp theo Thực hành trên file thật của bạn. Khi dữ liệu vượt quá Excel (> 1M dòng, nhiều nguồn) → học thêm Python + pandas hoặc SQL (có trong thư viện Mega Study). AI + Python + SQL = combo DA/AI Engineer đầy sức mạnh.
