Sends you over to our Beginners Series on YouTube, which is a great first-stop if you'd like to learn the basics of Procreate, or if you want to freshen up your skills.

Repeat brush upgrade

This allows you to reattempt the brush upgrade that occurs for users when they update from any version of Procreate prior to 5.4.

This will attempt the migration again, which may be useful if you have run into any issues with the migration process. The migration is moving all brushes you have stored within the Procreate app to the iPadOS file system (the Files app).

Remove brush upgrade backup

Upon a successful upgrade of the brush system, you can use this button to remove the local backup of your old brushes.

This may be useful if your brushes successfully upgraded (migrated) but the Procreate app is taking up too much space in Settings → General → iPad Storage.

Danger

Your upgrade backup is separate to your current brushes visible in Procreate and the Files app. If you remove the backup, you may be able to free some iPad space, but you will not be able to perform the brush upgrade again.

Send brush upgrade error report

If you have been having trouble with the brush upgrade after updating to Procreate 5.4 (or later), you can use this button to send a log of any brush update errors to our team directly.

This will open up your iPad's selected email app and pre-populate it with the log and the recipient information, so you can just send it out and it will reach our team.

We massively appreciate you sending this to us if you do have any trouble, as it might allow us to fix potential issues with brush upgrades.

Download 3D model pack

We have created a model pack with ready-to-use 3D models ideal for 3D painting in Procreate.

Tap to download the 3D model files into your gallery. Tapping any of the files will open them and automatically activate 3D Painting.

Advanced Settings

Opens up additional settings for Procreate, which are located in the Settings app → Apps → Procreate.

You can find more information about the Advanced Settings in the section immediately below.

Advanced Settings

Adjust advanced Procreate settings under the hood in the iPad Settings app.

You can adjust most settings from inside Procreate. Some settings are fundamental to how Procreate’s touch responses interact with iOS. To adjust these you need to head to the iOS setting for Procreate. Tap Actions → Help → Advanced Settings to go to iOS Settings. From here you can adjust these core functions.

Allow Access

Toggle which iPadOS apps Procreate can access.

Allow or deny Procreate access to Photos app, Bluetooth, the inbuilt camera, Siri, and Document Storage.

Some of these permissions are important to Procreate's functionality. For example, you will not be able to export an image from Procreate into Photos without allowing access. You can toggle access off and on anytime in Advanced Settings.

Pro Tip

To let other Apple devices access your Procreate files you can save them to iCloud Drive. To back up your artwork to iCloud Drive go to Gallery and tap Select. Then select all the artwork you wish to back up and tap Share > Procreate > Save to Files > iCloud Drive and select the folder you wish to store your files in.

Procreate Settings

Tweak basic Procreate functionality.

Canvas Orientation Memory

Switch this on to make Procreate remember which way you left your canvas oriented.

Fit Canvas Inside Interface

Toggle whether you prefer your canvas to be overlaid by Procreate’s interface or to fit inside it.

Disable Time-Lapse

This toggle turns Time-lapse Video recording for your creations on or off.

Simplified Undos

Toggle whether Undo remembers steps within modes separately, or combined them into a single step. An example of this would be if you perform a series of Transformations on selected content. If you then commit those transformations, Procreate can remember every individual step of the process. Or, it can also remember only the outcome of the transformation.

Simplified Undos are on by default. This means Procreate doesn’t remember individual steps within a mode. This allows you to reach further back when performing Undo.

Maximum Speed Distance

Determine the distance a stroke must travel before its Speed registers as 100%. If you find that brushes with speed-based settings are too sudden or sluggish for you. This is the setting to try changing for better results.

Drag and Drop Export

Set the preferred file format and image format for Drag-and-Drop exports. This means when you drag a canvas, Stack, or collection of canvases from the Gallery to Files or Photos.

  1. Preferred file format - sets the export format for canvases dragged to the Files app

  2. Preferred image format - sets the export format for canvases dragged to the Photos app
