# Glossary — Thuật ngữ Procreate (giữ nguyên tiếng Anh + chú thích Việt)

Quy ước dịch: **giữ thuật ngữ chuyên môn tiếng Anh** (tên nút/menu/công cụ trong app),
kèm **chú thích tiếng Việt** trong ngoặc đơn lần đầu xuất hiện. Sau đó chỉ dùng tiếng Anh.

Ví dụ: "Bấm **Layers** (Lớp) để..." → các lần sau viết "Bấm **Layers** để..."

## Tên công cụ / nút bấm (GIỮ NGUYÊN)

|---|---|
| Paint | Vẽ |
| Smudge | Nhòe / Pha màu |
| Erase | Tẩy |
| Layers | Lớp |
| Color | Màu |
| Gallery | Thư viện |
| Actions | Hành động |
| Adjustments | Điều chỉnh |
| Selections | Vùng chọn |
| Transform | Biến đổi |
| Brush | Cọ |
| Brush Studio | Trạm chỉnh cọ |
| Brush Library | Thư viện cọ |
| QuickMenu | Menu nhanh |
| QuickShape | Tự động cán nét |
| Drawing Assist | Trợ giúp vẽ |
| Eyedropper | Ống hút màu |
| Snapping | Bám dính |
| Warp | Bẻ cong |
| Distort | Co dạng |
| Freeform | Tự do |
| Uniform | Đồng đều |

## Từ thông thường (DỊCH HẲN)
app → ứng dụng | artwork → tác phẩm | feature → tính năng |
tap → chạm | drag → kéo | swipe → vuốt | pinch → chụp |
canvas → khung vẽ (khi nói chung, không phải tên nút)
