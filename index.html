🗺️ Roadmap AI Engineer

Lộ trình từ người mới đến Applied AI Engineer. Mỗi mục nối thẳng tới tài liệu trong thư viện. Muốn học theo học kì chi tiết, xem bản đầy đủ 32 tuần.

1

Lập trình & Tư duy Thuật toán

Thành thạo Python + DSA + SQL — nền móng qua vòng phỏng vấn
  • Python — Newbie → Early Senior (chạy code trong trình duyệt)
  • DSA — Cấu trúc dữ liệu & Giải thuật — Big-O, Tree/Graph, DP; tối ưu phỏng vấn
  • DBMS / SQL — PostgreSQL + SQL Playground chạy thật
  • Git — workflow nhóm, PR, xử lý conflict
  • Regex + Design Patterns — xử lý chuỗi & kiến trúc code
2

Hiểu hệ thống: Kiến trúc Máy tính & Mạng

Để code không treo máy & gọi được dịch vụ LLM
  • OS — Hệ điều hành — quản lý bộ nhớ, Process/Thread, đa luồng/đa tiến trình
  • Mạng máy tính — HTTP/TCP-UDP/DNS, API, latency
  • Computer Architecture + Concurrency — HK0: CPU/GPU/VRAM, GIL, async/await (B7–B8)
3

Nhập môn AI: Toán & ML cổ điển

Đừng đâm đầu vào Deep Learning — học bản chất trước
  • Toán nền (M1) — Đại số tuyến tính (ma trận/vector), Xác suất, Bayes, Gradient Descent
  • ML cổ điển — Linear/Logistic, Random Forest, XGBoost, KMeans/PCA
  • Feature Engineering & Data Pipeline — xử lý nhiễu, encoding, data leakage (phần Toán/Stats/Data)
4

Lõi AI: Deep Learning & Transformer

Mạng nơ-ron, CNN, Attention — trái tim AI tạo sinh
  • PyTorch + TensorFlow/Keras — MLP, Backprop, Adam/SGD, training loop
  • Computer Vision (CNN) — CNN/ResNet/YOLO/U-Net/ViT
  • NLP & Transformer — Attention, BERT/GPT, Hugging Face
  • Fine-tune (PEFT/LoRA) — tinh chỉnh LLM tiết kiệm
5

Ứng dụng AI: Prompt Engineering & RAG

Chuyển mình thành Applied AI Engineer — dùng mô hình có sẵn
  • Prompt Engineering nâng cao — ReAct, CoT, Chaining, Guardrails (5 cấp độ)
  • RAG — LangChain + LlamaIndex — chunking, vector DB, retrieve
  • Hybrid Search + Re-ranking (Cross-encoder) — lab dựng pipeline BM25+dense → RRF → rerank, đo recall@k
  • RAG Evaluation (RAGAS / TruLens) — chấm RAG định lượng: faithfulness, answer relevancy, context precision/recall
  • DSPy — tối ưu prompt bằng code (signature → compile)
  • MCP (Model Context Protocol) — chuẩn tool-connecting cho Agent; build server, cắm Claude Desktop
6

Trình độ Senior: MLOps & System Design

Đưa mô hình lên phục vụ hàng ngàn người dùng
  • MLOps (HK2) — FastAPI, Queue, CI/CD chạy eval, Docker
  • Evaluation + Observability — eval set, LLM-as-judge, trace (M8/M10)
  • Tối ưu chi phí & Streaming — caching ngữ nghĩa, route model, SSE/WebSocket
  • Quantization + serving LLM — lab end-to-end: model → quantize INT4 (AWQ/GGUF) → serve bằng vLLM
  • AI System Design (phỏng vấn Senior) — capacity estimation, trade-off, sharding, caching layer ở quy mô triệu user
