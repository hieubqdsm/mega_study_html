Chọn các thành phần của Curve¶

Trang này bàn về các công cụ chọn riêng cho curve object trong Edit Mode. Chế độ chỉnh sửa Curve cũng dùng các công cụ chọn chung được mô tả trong phần giao diện.

Việc chọn trên curve trong Edit Mode có ít tùy chọn hơn so với mesh. Chủ yếu là vì chỉ có một loại phần tử có thể chọn là các điểm điều khiển (nên ở đây không cần select mode...). Tuy nhiên, các điểm này hơi phức tạp hơn vertex đơn giản, đặc biệt là với curve Bézier, vì có vertex trung tâm cùng hai handle của nó...

Các công cụ cơ bản giống như với mesh, vì vậy bạn có thể chọn một điểm điều khiển bằng LMB, thêm vào lựa chọn hiện tại bằng Shift-LMB, Box Select B, v.v.

Một lưu ý về các điểm điều khiển Bézier: khi bạn chọn vertex trung tâm chính, hai handle cũng tự động được chọn, nên bạn có thể di chuyển toàn bộ mà không tạo ra góc gãy trên curve. Ngược lại, khi bạn chọn một handle, chỉ vertex đó được chọn, cho phép bạn chỉnh sửa vector điều khiển này...

Lưu ý rằng, khác với edge của mesh, bạn không thể chọn trực tiếp một đoạn. Thay vào đó, hãy chọn tất cả các điểm điều khiển tạo nên đoạn bạn muốn chỉnh sửa.

Select Menu¶

Với curve, tất cả các tùy chọn chọn "nâng cao" được gom trong menu Select ở header của 3D Viewport.

All¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ All

Shortcut:

A

Chọn tất cả các phần tử có thể chọn.

None¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ None

Shortcut:

Alt-A

Bỏ chọn tất cả các phần tử, nhưng phần tử active vẫn giữ nguyên.

Invert¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Invert

Shortcut:

Ctrl-I

Chọn toàn bộ phần hình học chưa được chọn, và bỏ chọn các thành phần đang được chọn.

Box Select¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Box Select

Shortcut:

B

Chọn khung tương tác.

Circle Select¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Circle Select

Shortcut:

C

Chọn vòng tròn tương tác.

Lasso Select¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Lasso Select

Shortcut:

Ctrl-Alt-LMB

Xem Select Lasso.

Select Random¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Select Random

Chọn ngẫu nhiên các điểm điều khiển.

Percent

Chọn tỷ lệ phần trăm điểm điều khiển đã chỉ định.

Random Seed

Seed được bộ sinh số ngẫu nhiên giả sử dụng.

Action

Điều khiển xem operator sẽ Chọn hay Bỏ chọn các điểm điều khiển.

Checker Deselect¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Checker Deselect

Công cụ này áp một mẫu checker xen kẽ chọn/bỏ chọn. Nó chỉ có tác dụng khi bạn đã chọn nhiều hơn một điểm điều khiển.

Nó hoạt động bằng cách thay đổi lựa chọn hiện tại sao cho chỉ mỗi điểm điều khiển thứ N mới còn được chọn, bắt đầu từ điểm active.

Deselected

Số phần tử bị bỏ chọn trong mỗi lần lặp lại của mẫu.

Selected

Số phần tử được chọn trong mỗi lần lặp lại của mẫu.

Offset

Độ dịch chuyển tính từ điểm bắt đầu.

Select More/Less¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ More/Less

Shortcut:

Ctrl-NumpadPlus, Ctrl-NumpadMinus

Dựa trên các điểm điều khiển đang được chọn, mục đích của chúng là thu nhỏ hoặc mở rộng lựa chọn này.

More

Với mỗi điểm điều khiển được chọn, chọn tất cả các điểm liên kết với nó (tức là một hoặc hai điểm...).

Less

Với mỗi điểm điều khiển được chọn, nếu tất cả các điểm liên kết với điểm này đều được chọn thì giữ điểm này ở trạng thái được chọn. Ngược lại, bỏ chọn nó.

Điều này kéo theo hai hệ quả:

  1. Khi tất cả điểm điều khiển của một curve được chọn thì sẽ không có gì xảy ra (với Less, mọi điểm liên kết luôn được chọn, và tất nhiên More không thể thêm điểm nào). Ngược lại, điều tương tự cũng đúng khi không có điểm điều khiển nào được chọn.

  2. Thứ hai, các công cụ này không bao giờ "đi ra ngoài" một curve (chúng không bao giờ "nhảy" sang curve khác trong cùng một object).

Select Linked¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Select Linked

Shortcut:

Ctrl-L

Chọn tất cả các điểm điều khiển được kết nối với điểm điều khiển active.

Operator này giúp việc chọn hoặc bỏ chọn toàn bộ các đoạn của một curve trở nên dễ dàng hơn, đặc biệt với các curve dày đặc hoặc phức tạp, khi việc chọn thủ công từng điểm sẽ tốn nhiều thời gian.

Select Linked Pick¶

Tham khảo

Mode:

Edit Mode

Hotkeys:

L, Shift-L

Chọn (L) hoặc bỏ chọn (Shift-L) các điểm điều khiển được kết nối với điểm điều khiển gần con trỏ chuột nhất.

Ghi chú

Với curve Bézier đang có một handle được chọn, operator chọn này sẽ chọn toàn bộ điểm điều khiển và cả tất cả các điểm liên kết với nó.

Select Similar¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Select Similar

Shortcut:

Shift-G

Chọn các điểm điều khiển có một số thuộc tính tương tự với điểm active. Panel Adjust Last Operation cung cấp một số tùy chọn chọn:

Type
Type

Chọn các spline có cùng kiểu spline, tức là Bézier, NURBS hoặc Poly.

Radius

Chọn các điểm điều khiển có giá trị Radius tương tự.

Weight

Chọn tất cả các điểm có giá trị Weight tương tự.

Direction

Chọn các điểm điều khiển có hướng handle tương tự.

Compare

Với các thuộc tính định lượng, thuộc tính này chọn kiểu so sánh giữa hai giá trị số.

Equal:

Chọn các phần tử có giá trị bằng với thuộc tính được chọn của phần tử active.

Greater:

Chọn các phần tử có giá trị lớn hơn thuộc tính được chọn của phần tử active.

Less:

Chọn các phần tử có giá trị nhỏ hơn thuộc tính được chọn của phần tử active.

Threshold

Với các thuộc tính định lượng, thuộc tính này quy định mức độ gần nhau giữa các giá trị của thuộc tính trong phép so sánh.

(De)select First/Last¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ (De)select First, Select ‣ (De)select Last

Các operator này sẽ bật/tắt trạng thái chọn của (các) điểm điều khiển đầu tiên hoặc cuối cùng của (các) curve trong object. Điều này hữu ích để nhanh chóng tìm điểm bắt đầu của một curve (ví dụ khi dùng nó làm path...).

Select Next/Previous¶

Tham khảo

Mode:

Edit Mode

Menu:

Select ‣ Select Next, Select ‣ Select Previous

Các operator này sẽ chọn (các) điểm điều khiển kế tiếp hoặc liền trước, dựa trên lựa chọn hiện tại (tức là các điểm điều khiển đi sau hoặc đi trước các điểm được chọn dọc theo curve). Trong trường hợp curve cyclic, điểm đầu tiên và điểm cuối cùng không được coi là liền kề.

Pick Shortest Path¶

Tham khảo

Mode:

Edit Mode

Menu:

Menu Search ‣ Pick Shortest Path

Shortcut:

Ctrl-LMB

Chọn các đoạn curve giữa hai điểm điều khiển: điểm active và điểm nằm dưới con trỏ. Trong trường hợp curve khép kín, đường đi ngắn nhất sẽ được chọn.
