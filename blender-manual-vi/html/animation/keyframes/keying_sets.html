Keying Set¶

Keying Set là tập hợp các thuộc tính animation, được dùng để tạo animation và keyframe cho nhiều thuộc tính cùng lúc. Ví dụ, nhấn K trong 3D Viewport sẽ hiện ra các Keying Set khả dụng. Blender sau đó sẽ thêm keyframe cho Keying Set được chọn. Có một số Keying Set tích hợp sẵn và cả các Keying Set tùy chỉnh gọi là "Absolute Keying Sets".

Panel Keying Set¶

Tham khảo

Editor:

Properties

Panel:

Scene ‣ Keying Set

Panel này dùng để thêm, chọn và quản lý các "Absolute Keying Sets".

Active Keying Set

Một List View các Keying Set trong scene đang hoạt động. Chọn một keying set sẽ kích hoạt nó

Add Empty Keying Set

Thêm một Keying Set trống.

Remove Active Keying Set

Xóa keying set đang hoạt động.

Mô tả

Mô tả ngắn về Keying Set.

Xuất ra File

Xuất Keying Set ra một script Python File.py. Để thêm lại Keying Set từ File.py, hãy mở rồi chạy File.py này trong Text Editor.

Panel Active Keying Set¶

Tham khảo

Editor:

Properties

Panel:

Scene ‣ Active Keying Set

Panel này dùng để thêm thuộc tính vào Keying Set đang hoạt động.

Paths

Một tập hợp đường dẫn trong List View, mỗi đường dẫn có một Data Path đến một thuộc tính để thêm vào Keying Set đang hoạt động.

Add Empty Keying Set Path

Thêm một đường dẫn trống.

Remove Active Keying Set Path

Xóa đường dẫn được chọn.

Target ID-Block

Đặt ID Type và đường dẫn dữ liệu Object IDs cho thuộc tính.

Data Path

Đặt phần còn lại của Data Path cho thuộc tính.

Array All Items

Dùng All Items từ Data Path hoặc chọn chỉ số mảng (array index) cho một thuộc tính cụ thể.

Nhóm F-Curve

Điều khiển việc các kênh sẽ được thêm vào nhóm nào.

Keying Set Name, None, Named Group

Cài đặt Keyframe¶

Ghi đè chung

Các tùy chọn này điều khiển mọi thuộc tính trong Keying Set. Lưu ý rằng các cài đặt tương tự trong Preferences sẽ ghi đè lên các cài đặt này nếu được bật.

Ghi đè cho tập đang hoạt động

Các tùy chọn này điều khiển từng thuộc tính riêng lẻ trong Keying Set.

Common Settings
Needed

Chỉ chèn keyframe ở những nơi cần thiết trong các F-Curve liên quan.

Visual

Chèn keyframe dựa trên phép biến đổi hiển thị (visual).

Thêm thuộc tính vào Keying Set¶

Tham khảo

Menu:

Context menu ‣ Add All/Single to Keying Set

Shortcut:

K

Một số cách để thêm thuộc tính vào Keying Set.

Nhấp RMB vào thuộc tính trong User Interface, rồi chọn Add Single to Keying Set hoặc Add All to Keying Set. Thao tác này sẽ thêm các thuộc tính vào Keying Set đang hoạt động, hoặc vào một Keying Set mới nếu chưa có keying set nào.

Di chuột tới các thuộc tính, rồi nhấn K để thực hiện Add All to Keying Set.

Đặt Keying Set đang hoạt động¶

Tham khảo

Shortcut:

Shift-K

Có vài cách để chỉ định keying set đang hoạt động:

  • Nhấn Shift-K trong 3D Viewport.

  • Chọn một keying set trong panel Keying Set.

  • Chọn một keying set trong popover Keyframing ở thanh tiêu đề của Timeline,

Keying Set Whole Character¶

Keying Set Whole Character tích hợp sẵn được tạo ra để keyframe mọi thuộc tính có khả năng được làm animation trong rig nhân vật.

Keying set này bỏ qua các bone có tên bắt đầu bằng một trong các tiền tố sau, vì nó coi đây là các bone kỹ thuật không dành cho việc làm animation trực tiếp. Chẳng hạn add-on Rigify tích hợp sẵn sẽ sinh ra các bone kiểu này.

  • COR (Corrective)

  • DEF (Deformation)

  • GEO (Geometry)

  • MCH (Mechanism)

  • ORG (Original from meta rig)

  • VIS (Visualization)
