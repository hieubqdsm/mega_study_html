Link & Append¶

Các chức năng này giúp bạn tái sử dụng object, material và các data-block khác từ một blend-file khác. Bạn có thể xây dựng các thư viện nội dung dùng chung và chia sẻ chúng giữa nhiều file tham chiếu.

Mẹo

Thay vì dùng menu, bạn cũng có thể Link/Append các blend-file bằng cách kéo và thả chúng vào cửa sổ Blender.

Ghi chú

Không thể Link hoặc Append dữ liệu từ các blend-file mới hơn nhiều.

Link¶

Tham khảo

Editor:

Topbar

Mode:

Mọi mode trừ Edit Mode

Menu:

File ‣ Link...

Link tạo một tham chiếu đến dữ liệu trong file nguồn sao cho các thay đổi được thực hiện ở đó sẽ được phản ánh vào file hiện tại vào lần tải lại kế tiếp. Trong File Browser, điều hướng đến blend-file nguồn bên ngoài và chọn các data-block bạn muốn tái sử dụng.

Các data-block được link được biểu thị bằng biểu tượng hình sợi xích trong Outliner. Chúng cũng được liệt kê trong Display Mode Blender File của Outliner, cùng với đường dẫn của blend-file mà chúng xuất phát từ đó.

Ban đầu, các data-block được link không thể chỉnh sửa. Điều này thậm chí bao gồm cả vị trí/góc quay/tỉ lệ scale của các object được link, vốn bị khóa theo phép biến đổi mà chúng có trong file nguồn. Tuy nhiên, vẫn có một số cách khắc phục:

  • Nếu bạn link một collection với Instance Collections được bật, hoặc một object data nào đó với Instance Object Data được bật, collection/object data đó sẽ được tham chiếu qua một object được tạo bên trong blend-file hiện tại, object này có thể được biến đổi. (Object mới này sẽ được tạo tại 3D Cursor.)

  • Bạn cũng có thể chỉnh sửa/tạo animation ở mức độ nhất định trên các data-block được link (vì vậy thường bị khóa) bằng cách dùng Library Overrides.

Cảnh báo

Vì không thể chỉnh sửa nên dữ liệu được link không thể được bảo vệ bằng tùy chọn Fake User. Thêm một custom property trỏ đến một data-block được link nếu không thì không được dùng đến (ví dụ một Text block) là một cách tốt để giữ cho nó được tham chiếu qua các lần lưu và tải lại.

Tùy chọn¶

Các tùy chọn này có sẵn trong panel bên phải của File Browser.

Relative Path

Tham chiếu blend-file bên ngoài bằng đường dẫn tương đối thay vì đường dẫn tuyệt đối.

Select

Chọn các object mới thêm vào.

Active Collection

Khi được bật, các object và collection sẽ được thêm vào collection đang hoạt động của view layer đang hoạt động. Nếu không, chúng sẽ được thêm vào một collection "Linked Data" mới trong view layer đang hoạt động.

Instance Collections

Khi được bật, mỗi collection được link sẽ được thêm vào scene dưới dạng một instance collection (tức là một object duy nhất đại diện cho toàn bộ collection). Bạn có thể thêm các instance như vậy bằng Add ‣ Collection Instance, hoặc thay thế một instance bằng nội dung của collection dùng Make Instances Real.

Khi bị tắt, các collection sẽ được thêm vào nguyên trạng để bạn có thể xem nội dung của chúng trong Outliner và tạo Library Overrides.

Instance Object Data

Khi được bật, một object sẽ được tạo cho từng object data được link trực tiếp. Nếu không, sẽ không có object nào được tạo và object data sẽ không hiển thị trong scene cho đến khi bạn tự tạo một object (ví dụ bằng cách kéo object data từ Outliner vào 3D Viewport).

Append¶

Tham khảo

Editor:

Topbar

Mode:

Mọi mode trừ Edit Mode

Menu:

File ‣ Append...

Append sao chép các data-block vào blend-file của bạn mà không giữ bất kỳ tham chiếu nào đến bản gốc. Bạn có thể tiếp tục chỉnh sửa bản sao cục bộ của dữ liệu, nhưng các thay đổi trong file nguồn bên ngoài sẽ không được phản ánh vào file hiện tại.

Trong File Browser, điều hướng đến blend-file nguồn bên ngoài và chọn các data-block bạn muốn tái sử dụng.

Ghi chú

Append một dữ liệu mà bạn đã link sẽ thêm các object/collection vào scene, nhưng sẽ giữ chúng ở trạng thái được link (và không chỉnh sửa được).

Điều này được thực hiện để các quan hệ hiện có với dữ liệu được link vẫn được giữ nguyên.

Tùy chọn¶

Các tùy chọn này có sẵn trong panel bên phải của File Browser.

Select

Chọn các object mới thêm vào.

Active Collection

Khi được bật, các object và collection sẽ được thêm vào collection đang hoạt động của view layer đang hoạt động. Nếu không, chúng sẽ được thêm vào một collection "Appended Data" mới trong view layer đang hoạt động.

Instance Collections

Khi được bật, mỗi collection được append sẽ được thêm vào scene dưới dạng một instance collection (tức là một object duy nhất đại diện cho toàn bộ collection). Bạn có thể thêm các instance như vậy bằng Add ‣ Collection Instance, hoặc thay thế một instance bằng nội dung của collection dùng Make Instances Real.

Khi bị tắt, các collection sẽ được thêm vào nguyên trạng để bạn có thể xem nội dung của chúng trong Outliner.

Instance Object Data

Khi được bật, một object sẽ được tạo cho từng object data được append trực tiếp. Nếu không, sẽ không có object nào được tạo và object data sẽ không hiển thị trong scene cho đến khi bạn tự tạo một object (ví dụ bằng cách kéo object data từ Outliner vào 3D Viewport).

Fake User

Đánh dấu các data-block được append là Được bảo vệ.

Localize All

Đồng thời sao chép tất cả dữ liệu được link gián tiếp, thay vì duy trì các link.

Reload Library¶

Tham khảo

Editor:

Outliner

Menu:

Context menu ‣ Reload

Khi Outliner đang ở Display Mode Blender File, bạn có thể nhấp chuột phải vào một blend-file được link và chọn Reload để cập nhật ngay blend-file hiện tại với phiên bản mới nhất của các data-block được link, mà không cần mở lại file.

Relocate Library¶

Tham khảo

Editor:

Outliner

Menu:

Context menu ‣ Relocate

Khi Outliner đang ở Display Mode Blender File, việc nhấp chuột phải vào một thư viện (một blend-file được link) sẽ hiện tùy chọn Relocate. Nó cho phép thay thế thư viện đó bằng một file khác. Tính năng này có thể được dùng để sửa một thư viện được link bị lỗi (ví dụ vì file bị di chuyển hoặc đổi tên), hoặc để chuyển sang một biến thể của cùng dữ liệu nằm ở file khác.

Thư Viện Bị Lỗi¶

Nếu Blender không thể tìm thấy một thư viện trong khi tải blend-file, nó sẽ tạo các data-block placeholder để thay thế những data-block được link còn thiếu. Nhờ đó, các tham chiếu đến dữ liệu bị mất không bị mất đi, và bằng cách relocate thư viện bị thiếu, dữ liệu đã mất có thể được khôi phục tự động.

Relocate Linked ID¶

Tham khảo

Editor:

Outliner

Menu:

Context menu ‣ ID Data ‣ Relocate

Nhấp chuột phải vào một ID được link sẽ hiện tùy chọn Relocate trong menu con ID Data. Nó cho phép relocate một ID được link trực tiếp bằng một ID khác, từ cùng thư viện hoặc từ thư viện khác. Tính năng này có thể được dùng để sửa một data-block được link bị lỗi (ví dụ vì ID bị đổi tên), hoặc để chuyển sang một biến thể của cùng dữ liệu.

Ghi chú

Thao tác này chỉ có sẵn trên các data-block được link trực tiếp, và không phải là phần phụ thuộc của bất kỳ dữ liệu được link nào khác.

Make Local¶

Tham khảo

Editor:

3D Viewport

Mode:

Object Mode

Menu:

Object ‣ Relations ‣ Make Local...

Tham khảo

Editor:

Outliner

Menu:

Context menu ‣ ID Data ‣ Make Local

Chuyển các object được chọn hoặc tất cả object bên ngoài thành cục bộ đối với blend-file hiện tại. Các link đến file thư viện gốc sẽ bị mất, nhưng các data-block sẽ trở nên chỉnh sửa được hoàn toàn, giống như những data-block được tạo trực tiếp trong blend-file hiện tại.

Tùy chọn¶

Thao tác có sẵn từ context menu của Outliner không có tùy chọn nào và chỉ ảnh hưởng đến các data-block được chọn.

Thao tác có sẵn từ 3D Viewport chỉ ảnh hưởng đến các object được chọn, nhưng nó cũng có thể chuyển các phần phụ thuộc của object thành cục bộ:

Type

Chỉ chuyển bản thân các object thành cục bộ, hay cả dữ liệu và material của chúng.

Hạn chế đã biết¶

Phần lớn việc link dữ liệu sẽ hoạt động như mong đợi. Tuy nhiên, có một số hạn chế cần lưu ý.

Phụ Thuộc Vòng¶

Nói chung, các phần phụ thuộc không nên đi theo cả hai chiều. Cố link hoặc append dữ liệu mà nó link ngược lại file hiện tại nhiều khả năng sẽ dẫn đến thiếu link.

Cài Đặt Cấp Scene¶

Các cài đặt cấp scene như Rigid Body World sẽ không được sao chép khi link object. Để thay thế, bạn có thể link toàn bộ scene và dùng nó làm Background Scene.

Nén & Sử Dụng Bộ Nhớ¶

Tham chiếu các blend-file đã nén có thể cần rất nhiều bộ nhớ vì chúng phải được tải toàn bộ, ngay cả khi bạn chỉ link/append một phần nhỏ của chúng. Tuy nhiên, một khi các data-block đã được tải, mức sử dụng bộ nhớ là như nhau.
