Cài đặt trên Windows¶

Hướng dẫn này bao gồm các chủ đề sau:

  1. Cài đặt Python (dùng để "chuyển đổi" các file nguồn sang HTML)

  2. Cài đặt Git và Tải repository

  3. Thiết lập môi trường Build

Cài đặt Python¶

  1. Tải xuống gói cài đặt Python cho Windows. Trong hướng dẫn này, phiên bản 3.9.x được sử dụng.

  2. Cài đặt Python bằng trình hướng dẫn cài đặt. Vui lòng đảm bảo rằng bạn bật tùy chọn "Add Python to PATH":

    Tất cả các cài đặt khác có thể giữ nguyên theo mặc định.

Cài đặt Git và Tải repository¶

Trong hướng dẫn này, chúng tôi sẽ dùng trình Git khách chính thức, dù bất kỳ Git client nào cũng được.

  1. Tải xuống và cài đặt Git cho Windows.

  2. Chỉ cần checkout repository của Blender Manual bằng lệnh:

    cd ~
git lfs install
git clone https://projects.blender.org/blender/blender-manual.git

  3. Repository bây giờ sẽ được tải xuống, có thể mất vài phút tùy vào kết nối internet của bạn.

Ghi chú

Quá trình này có thể được hoàn tất bằng một Git client đồ họa, khi đó bạn chỉ cần dùng địa chỉ repository trong ô URL mà client cung cấp:

https://projects.blender.org/blender/blender-manual.git

Thiết lập môi trường Build¶

  • Mở một cửa sổ Terminal.

  • Vào thư mục blender-manual vừa được thêm bởi git clone:

    cd C:\blender-manual

  • Cài đặt các dependency:

    make setup

  • Nếu mọi thứ suôn sẻ, bạn sẽ thấy thông báo sau khi quá trình hoàn tất:

    Successfully installed Jinja2 MarkupSafe Pygments Sphinx docutils sphinx-rtd-theme Cleaning up...

Trong quá trình thiết lập, một số cảnh báo có thể xuất hiện, nhưng đừng lo lắng về chúng. Tuy nhiên, nếu có bất kỳ lỗi nào xảy ra, chúng có thể gây ra một số vấn đề.

Ghi chú

Thi thoảng bạn cần chạy lại lệnh này, để đảm bảo các dependency được cập nhật.

Mẹo

make setup tự động tạo một môi trường ảo bằng các lệnh sau:

python -m venv .venv
.venv/Scripts/pip install -r requirements.txt

Điều này tránh can thiệp vào bản cài đặt Python của hệ thống, tuân theo PEP 668

Lệnh Sphinx có sẵn tại:

.venv/Scripts/sphinx-build
