Selecting¶

Theo mặc định, Blender dùng LMB để chọn mục. Điều này có thể đổi thành RMB trong Preferences.

Blender có một số công cụ chọn có thể dùng được trong các editor khác nhau.

Ghi chú

Một số editor lệch khỏi các phím tắt được trình bày dưới đây. Ví dụ, phần lớn editor dùng Shift-LMB để thêm một mục vào lựa chọn, nhưng Outliner dùng Ctrl-LMB. Tương tự, phần lớn editor dùng Ctrl-RMB để thực hiện Lasso Select, nhưng node editor dùng Ctrl-Alt-LMB.

Phần lớn công cụ chọn có hai biến thể, một biến thể nằm trong Toolbar và biến thể kia nằm trong menu Select. Dù tên của các biến thể gần như giống hệt nhau (như Select Box trong Toolbar đối lại với Box Select trong menu), cách chúng hoạt động hơi khác nhau. Người dùng mới đến từ ứng dụng khác sẽ thấy các biến thể trong Toolbar quen thuộc nhất.

Công cụ chọn trong Toolbar¶

Tất cả công cụ chọn trong Toolbar đều hành xử giống nhau khi nhấp vào một mục: chúng chọn mục đó (và bỏ chọn mọi mục đã chọn trước đó). Nếu bạn giữ Shift khi nhấp, mục sẽ được thêm vào lựa chọn (nếu nó chưa được chọn) hoặc bị loại khỏi lựa chọn (nếu nó đã được chọn).

Điều khiến các công cụ khác nhau là chuyện gì xảy ra khi bạn kéo.

Tweak¶

Tham khảo

Tool:

Toolbar ‣ Tweak

Shortcut:

W

Kéo một mục sẽ di chuyển nó đi.

Select Box¶

Tham khảo

Tool:

Toolbar ‣ Select Box

Shortcut:

W

Kéo sẽ tạo một hình chữ nhật, và chọn tất cả các mục nằm một phần hoặc hoàn toàn bên trong nó khi bạn thả chuột. (Mọi mục khác sẽ bị bỏ chọn.)

Giữ Shift khi kéo sẽ thêm các mục vào lựa chọn. Giữ Ctrl sẽ loại chúng ra.

Trong khi kéo, bạn có thể giữ thêm Spacebar để di chuyển hình chữ nhật theo chuột.

Ví dụ Select Box (Edit Mode).¶

Select Circle¶

Tham khảo

Tool:

Toolbar ‣ Select Circle

Shortcut:

W

Kéo sẽ chọn tất cả các mục mà vòng tròn đi qua. Những mục nào bạn không đi qua sẽ bị bỏ chọn.

Giữ Shift khi kéo sẽ thêm các mục vào lựa chọn. Giữ Ctrl sẽ loại chúng ra.

Bạn có thể đổi bán kính của vòng tròn trong cài đặt công cụ (có thể tìm thấy trong header của vùng làm việc, tab Tool của Sidebar N, hoặc tab Active Tool của Properties editor).

Ghi chú

Trong Object Mode: khác với Select Box vốn chọn object ngay khi hộp che bất kỳ phần hình học nào của chúng, Select Circle chỉ chọn object nếu vòng tròn đi qua điểm origin của chúng. Origin hiển thị dưới dạng chấm màu cam cho object được chọn nhưng vô hình với object chưa chọn, trừ khi "Origins (All)" được bật trong Viewport Overlays.

Sự khác biệt về hành vi này không áp dụng cho các mode khác (như Edit Mode và Pose Mode).

Ví dụ Select Circle (Edit Mode).¶

Select Lasso¶

Tham khảo

Tool:

Toolbar ‣ Select Lasso

Shortcut:

W

Kéo sẽ tạo một hình dạng tự do, và chọn tất cả các mục bên trong nó khi bạn thả chuột. (Mọi mục khác sẽ bị bỏ chọn.)

Giữ Shift khi kéo sẽ thêm các mục vào lựa chọn. Giữ Ctrl sẽ loại chúng ra.

Trong khi kéo, bạn có thể giữ thêm Spacebar để di chuyển hình dạng theo chuột.

Ghi chú

Select Lasso hành xử giống Select Circle ở chỗ nó chỉ xét đến điểm origin trong Object Mode.

Ví dụ Select Lasso (Edit Mode).¶

Selection Modes¶

Tham khảo

Tool:

Select Tools

Panel:

Tool Settings ‣ Mode

Mỗi công cụ chọn trong Toolbar có một mode để cấu hình cách nó tương tác với lựa chọn hiện có. Lưu ý rằng không phải công cụ nào cũng hỗ trợ tất cả các mode này.

Set

Đặt một lựa chọn mới (lựa chọn trước đó bị bỏ). Đây là mặc định.

Extend

Thêm các mục mới chọn vào lựa chọn hiện có.

Subtract

Loại các mục mới chọn khỏi lựa chọn hiện có.

Invert Ctrl-I

Đảo ngược lựa chọn (mục chưa chọn trở thành được chọn và ngược lại).

Intersect

Chọn các mục giao với lựa chọn hiện có.

Công cụ chọn trong menu¶

Các công cụ này là biến thể của những công cụ vừa mô tả. Chúng có trong menu thay vì trong Toolbar và hoạt động hơi khác một chút.

Box Select¶

Tham khảo

Menu:

Select ‣ Box Select

Shortcut:

B

Để dùng công cụ này, bạn trước tiên kích hoạt mục menu hoặc phím tắt rồi kéo một hộp như thường lệ. Khác với Select Box, hành vi mặc định ở đây là thêm các mục bên trong hộp vào lựa chọn. (Những mục bên ngoài hộp không bị bỏ chọn.)

Để loại các mục bên trong hộp khỏi lựa chọn, hãy giữ Shift, hoặc kéo bằng MMB thay thế.

Trong khi kéo, bạn có thể giữ thêm Spacebar để di chuyển hộp theo chuột.

Circle Select¶

Tham khảo

Menu:

Select ‣ Circle Select

Shortcut:

C

Để dùng công cụ này, bạn trước tiên kích hoạt mục menu hoặc phím tắt rồi kéo một vòng tròn như thường lệ. Khác với Select Circle, hành vi mặc định ở đây là thêm các mục bên trong vòng tròn vào lựa chọn. (Những mục bên ngoài vòng tròn không bị bỏ chọn.)

Để loại các mục bên trong vòng tròn khỏi lựa chọn, hãy giữ Shift, hoặc kéo bằng MMB thay thế.

Bạn có thể đổi bán kính của vòng tròn bằng cách lăn Wheel hoặc dùng các phím NumpadPlus và NumpadMinus.

Một khi đã kích hoạt, Circle Select giữ nguyên trạng thái hoạt động: bạn có thể thả nút chuột và bắt đầu kéo ở chỗ khác mà không cần nhấn C lại. Tuy nhiên, cùng lúc đó, nó chặn mọi phần khác của Blender khi đang hoạt động. Để tắt công cụ trở lại, hãy nhấn RMB, Return, hoặc Esc.

Lasso Select¶

Tham khảo

Menu:

Select ‣ Lasso Select

Shortcut:

Ctrl-RMB

Để dùng công cụ này, bạn trước tiên kích hoạt mục menu và kéo một hình dạng tự do quanh (các) mục muốn chọn bằng LMB. Menu cho phép bạn chọn việc đặt, mở rộng hay thu hẹp lựa chọn.

Ngoài ra, bạn có thể lập tức bắt đầu kéo bằng Ctrl-RMB. Khác với Select Lasso, hành vi mặc định khi đó là thêm các mục bên trong lasso vào lựa chọn. (Những mục bên ngoài lasso không bị bỏ chọn.)

Để loại các mục bên trong lasso khỏi lựa chọn, hãy kéo bằng Shift-Ctrl-RMB thay thế.

Trong khi kéo, bạn có thể giữ thêm Spacebar để di chuyển lasso theo chuột.
