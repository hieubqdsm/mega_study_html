Giới thiệu¶

Python là một ngôn ngữ lập trình thông dịch, tương tác và hướng đối tượng. Nó bao gồm các module, exception, dynamic typing, các kiểu dữ liệu động cấp rất cao và class. Python kết hợp sức mạnh vượt trội với cú pháp rất rõ ràng.

Python script là một cách linh hoạt để mở rộng chức năng của Blender. Hầu hết các khu vực của Blender đều có thể được script hóa, bao gồm animation, render, import và export, tạo object cũng như tự động hóa các tác vụ lặp đi lặp lại.

Để tương tác với Blender, script có thể sử dụng API được tích hợp chặt chẽ.

Thông tin Chung¶

Các liên kết hữu ích khi viết script:

  • Python.org -- Thông tin chung về Python.

  • Blender Python API -- Tài liệu API chính thức. Hãy dùng tài liệu này để tra cứu khi viết script.

  • API Introduction -- Giới thiệu ngắn giúp bạn làm quen với API. Có kèm ví dụ.

Các liên kết liên quan đến việc phân phối script của bạn:

  • Creating Add-ons -- Add-on được dùng để đóng gói và phân phối script.

  • Tạo Extension -- Chia sẻ add-on trên nền tảng Blender Extensions.

Mở rộng Blender¶

Add-ons¶

Add-on là các script giúp Blender có thêm chức năng; chúng có thể được bật từ Preferences.

Ngoài file thực thi của Blender, còn có hàng trăm add-on do nhiều người viết:

  • Các add-on được hỗ trợ chính thức được đóng gói kèm Blender.

  • Các add-on khác được cung cấp bởi Blender Extensions, không thuộc các bản phát hành chính thức. Nhiều add-on trong số đó hoạt động đáng tin cậy và rất hữu ích, nhưng chưa được đảm bảo đủ ổn định để đưa vào bản phát hành.

Xem thêm

Xem Add-ons để tìm tài liệu về các add-on đi kèm Blender.

Script¶

Ngoài add-on, còn có một số loại script khác mở rộng chức năng của Blender:

Module:

Các thư viện tiện ích để import vào các script khác.

Presets:

Cài đặt cho các công cụ và cấu hình phím của Blender.

Startup:

Các file này được import khi khởi động Blender. Chúng định nghĩa phần lớn UI của Blender, cũng như một số operator cốt lõi bổ sung.

Script Tùy chỉnh:

Khác với add-on, chúng thường được dùng để thực thi một lần qua Text Editor.

Lưu Script của riêng bạn¶

Vị trí File¶

Tất cả script được tải từ thư mục scripts của các đường dẫn local, system và user.

Bạn có thể thiết lập một đường dẫn tìm kiếm bổ sung cho script trong File Paths Preferences ‣ File Paths.

Cài đặt¶

Add-on được cài đặt một cách thuận tiện ngay trong Blender qua Preferences. Nhấp vào nút Install... và chọn file .zip.
