Application Template¶

Cách dùng¶

Application template là một tính năng cho phép bạn định nghĩa một cấu hình có thể tái sử dụng, có thể được chọn để thay thế cấu hình mặc định, mà không cần một bản cài Blender riêng hay ghi đè lên cài đặt cá nhân của bạn.

Application template có thể được chọn từ màn hình splash hoặc menu con File ‣ New. Khi không tìm thấy template nào, menu sẽ không được hiển thị trên màn hình splash.

Các application template mới có thể được cài đặt từ Menu Blender. Nếu bạn muốn giữ application template hiện tại được kích hoạt khi khởi động lại Blender, hãy lưu tùy chỉnh của bạn.

Động lực¶

Trong một số trường hợp, việc viết một script hay add-on đơn lẻ rồi mong người khác thay thế tùy chỉnh và file khởi động của họ, cài đặt script và thay đổi keymap của họ là chưa đủ.

Mục tiêu của application template là hỗ trợ chuyển sang một cấu hình tùy chỉnh mà không làm gián đoạn các cài đặt và bản cài đặt hiện có của bạn. Điều này có nghĩa là mọi người có thể xây dựng các ứng dụng riêng của mình trên nền Blender để dễ dàng phân phối.

Details¶

Một application template có thể tự định nghĩa:

File khởi động

File mặc định được tải cùng template này.

Preferences

Chỉ một số tùy chỉnh nhất định từ template được sử dụng:

  • Theme.

  • Add-on.

  • Keymap.

  • Ánh sáng của viewport.

Splash Screen

Template có thể cung cấp ảnh màn hình splash riêng của mình.

Script Python

Mặc dù template có quyền truy cập cùng chức năng như bất kỳ script nào khác, các thao tác điển hình bao gồm:

  • Sửa đổi và thay thế các phần của giao diện người dùng.

  • Định nghĩa menu, keymap và công cụ mới.

  • Định nghĩa đường dẫn add-on tùy chỉnh cho các add-on riêng của template.

Template cũng có cấu hình người dùng riêng, nên việc lưu file khởi động khi đang dùng template sẽ không ghi đè file khởi động mặc định của bạn.

Bố cục thư mục¶

Template có thể nằm ở một trong hai vị trí trong thư mục scripts.

Các vị trí đặt template:
{BLENDER_USER_SCRIPTS}/startup/bl_app_templates_user
{BLENDER_SYSTEM_SCRIPTS}/startup/bl_app_templates_system

Cấu hình người dùng được lưu trong một thư mục con:

Không dùng template:
./config/startup.blend
./config/userpref.blend
Có dùng template:
./config/{APP_TEMPLATE_ID}/startup.blend
./config/{APP_TEMPLATE_ID}/userpref.blend

Xem Bố cục thư mục của Blender để biết chi tiết về vị trí script và cấu hình.

Gợi ý

Xử lý sự cố đường dẫn

Khi tạo application template, bạn có thể gặp vấn đề đường dẫn không được tìm thấy. Để điều tra, bạn có thể ghi log đầu ra của tất cả các lần tra cứu đường dẫn của Blender.

Ví dụ về các đối số dòng lệnh tải Blender với một application template tùy chỉnh (thay my_app_template bằng tên template của riêng bạn):

blender --log "bke.appdir.*" --log-level -1 --app-template my_app_template

Sau đó bạn có thể kiểm tra các đường dẫn nơi có các thao tác thử truy cập my_app_template.

Truy cập qua dòng lệnh¶

Sử dụng đối số dòng lệnh, bạn có thể thiết lập một launcher mở Blender với một app template cụ thể:

blender --app-template my_template

Nội dung template¶

Mỗi file sau đây có thể được dùng cho application template nhưng là tùy chọn.

startup.blend

File khởi động dạng factory dùng cho template này.

userpref.blend

File tùy chỉnh dạng factory dùng cho template này. Nếu bỏ qua, tùy chỉnh sẽ dùng chung với cấu hình Blender mặc định.

(Như đã ghi chú trước đó, điều này chỉ được dùng cho một phần nhỏ trong các tùy chỉnh).

splash.png

Màn hình splash để ghi đè hình ảnh mặc định của Blender (không bao gồm phần chữ tiêu đề). Lưu ý, ảnh này phải là ảnh kích thước 1000x500.

__init__.py

Một script Python phải chứa các hàm register và unregister.

Ghi chú

Các blend file đóng gói kèm startup.blend và userpref.blend được coi là Factory Settings và không bao giờ bị ghi đè.

Người dùng có thể lưu file khởi động/tùy chỉnh riêng của mình khi dùng template này; chúng sẽ được lưu trong cấu hình người dùng của họ, nhưng chỉ khi template có file userpref.blend riêng.

Các cài đặt template gốc có thể được tải bằng: Load Template Factory Settings từ menu file, hoạt động theo cách giống hệt Load Factory Settings.

Script của template¶

Mặc dù app template có thể dùng script Python, chúng đơn giản là có quyền truy cập cùng các API có sẵn cho add-on và bất kỳ script nào khác.

Như đã ghi chú ở trên, bạn có thể tùy chọn có một __init__.py trong app template của mình. Điều này có các ưu điểm sau:

  • Có thể thực hiện các thay đổi đối với file khởi động hoặc tùy chỉnh mà không phải phân phối blend file.

  • Các thay đổi có thể được thực hiện động.

    Ví dụ, bạn có thể -- cấu hình template để kiểm tra số lượng bộ xử lý, hệ điều hành và bộ nhớ, rồi đặt các giá trị dựa trên thông tin đó.

  • Bạn có thể bật các add-on liên quan đến template của mình.

Khi kích hoạt, hàm register được gọi; unregister được gọi khi một template khác được chọn.

Vì các hàm này chỉ chạy một lần, mọi thay đổi đối với giá trị mặc định phải được thực hiện qua handler. Hai handler mà bạn nhiều khả năng sẽ dùng là:

  • bpy.app.handlers.load_factory_preferences_post

  • bpy.app.handlers.load_factory_startup_post

Chúng cho phép bạn định nghĩa "factory settings" riêng của mình, mà người dùng có thể thay đổi, giống như Blender có các giá trị mặc định riêng khi lần đầu được khởi chạy.

Đây là một file __init__.py mẫu định nghĩa các giá trị mặc định để app template sử dụng.

import bpy
from bpy.app.handlers import persistent

@persistent
def load_handler_for_preferences(_):
    print("Changing Preference Defaults!")
    from bpy import context

    prefs = context.preferences
    prefs.use_preferences_save = False

    kc = context.window_manager.keyconfigs["blender"]
    kc_prefs = kc.preferences
    if kc_prefs is not None:
        kc_prefs.select_mouse = 'RIGHT'
        kc_prefs.spacebar_action = 'SEARCH'
        kc_prefs.use_pie_click_drag = True

    view = prefs.view
    view.header_align = 'BOTTOM'


@persistent
def load_handler_for_startup(_):
    print("Changing Startup Defaults!")

    # Use smooth faces.
    for mesh in bpy.data.meshes:
        for poly in mesh.polygons:
            poly.use_smooth = True

    # Use material preview shading.
    for screen in bpy.data.screens:
        for area in screen.areas:
            for space in area.spaces:
                if space.type == 'VIEW_3D':
                    space.shading.type = 'MATERIAL'
                    space.shading.use_scene_lights = True


def register():
    print("Registering to Change Defaults")
    bpy.app.handlers.load_factory_preferences_post.append(load_handler_for_preferences)
    bpy.app.handlers.load_factory_startup_post.append(load_handler_for_startup)

def unregister():
    print("Unregistering to Change Defaults")
    bpy.app.handlers.load_factory_preferences_post.remove(load_handler_for_preferences)
    bpy.app.handlers.load_factory_startup_post.remove(load_handler_for_startup)
