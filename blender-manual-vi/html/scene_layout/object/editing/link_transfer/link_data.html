Link Data¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Link/Transfer Data

Shortcut:

Ctrl-L

Thực hiện nhiều loại gán khác nhau: thêm một object vào scene, cho một object dùng cùng dữ liệu hoặc modifier như một object khác, v.v.

Khi bạn liên kết hai object với cùng một dữ liệu, thay đổi thực hiện trên object này cũng sẽ xuất hiện trên object kia. Nếu không còn muốn vậy, bạn có thể dùng Tạo Single User để mỗi object một lần nữa có dữ liệu riêng của mình.

Link Objects to Scene

Thêm các object đã chọn vào scene được chỉ định. Object có thể tồn tại đồng thời trong nhiều scene và có cùng vị trí/animation trong tất cả các scene đó.

Link Object Data

Thay thế dữ liệu object của các object đã chọn bằng dữ liệu của active object.

Link Materials

Thay thế các material của các object đã chọn bằng material của active object.

Link Animation Data

Thay thế action và track của các object đã chọn bằng các action và track của active object.

Link Collections

Chuyển các object đã chọn vào cùng collection với active object.

Link Instance Collection

Thay thế instance collection của các object đã chọn bằng instance collection của active object.

Link Fonts to Text

Thay thế font của các text object đã chọn bằng font của text object đang hoạt động.

Copy Modifiers

Thay thế các modifier của các object đã chọn bằng modifier của active object.

Copy Constraints

Thay thế các constraint của các object đã chọn bằng constraint của active object.

Copy Grease Pencil Effects

Thay thế các visual effect của các object Grease Pencil đã chọn bằng visual effect của active object.

Copy Light Linking

Thay thế collection Light Linking đã gán của các object đã chọn bằng collection của active object.

Copy Shadow Linking

Thay thế collection Shadow Linking đã gán của các object đã chọn bằng collection của active object.

Copy UV Maps

Thay thế UV map đang hoạt động của mỗi mesh object đã chọn bằng UV map đang hoạt động của active object. Nếu một object được chọn chưa có UV map nào thì một UV map sẽ được tạo.

Tất cả các object phải có geometry và thứ tự face khớp nhau. Bạn có thể đảm bảo thứ tự này bằng Sort Elements, nhưng kể cả vậy, operator này thực sự chỉ hữu ích khi đích là một bản sao đã biến dạng của nguồn. Hãy dùng Transfer Mesh Data cho các trường hợp khác.
