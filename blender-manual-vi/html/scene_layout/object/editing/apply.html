Apply¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply

Shortcut:

Ctrl-A

Các thao tác này cho phép bạn áp một số phép biến đổi vào các object đang được chọn. Tọa độ biến đổi của object được chuyển vào dữ liệu của object. Nếu các object có hậu duệ theo phân cấp, các phép biến đổi đó cũng được áp lên con của chúng.

Transforms¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply ‣ Location / Rotation / Scale / Rotation & Scale

Việc áp transform đặt lại các giá trị Location, Rotation hoặc Scale của object trong khi về mặt thị giác object vẫn ở nguyên chỗ. Trên thực tế, điều này có nghĩa là:

  • Origin của object được di chuyển đến origin global (đối với vị trí).

  • Các giá trị góc quay được xóa về không.

  • Các giá trị scale được đặt lại thành 1.0.

Bản thân hình học được điều chỉnh sao cho object vẫn hiển thị không đổi trong 3D Viewport và bản render cuối.

Với các trường hợp đơn giản bạn có thể không nhận ra khác biệt, nhưng việc áp transform có thể ảnh hưởng đến cách hoạt động của modifier, constraint và parenting, vì chúng thường phụ thuộc vào các giá trị transform của object.

Cảnh báo

Object Armature

Việc áp transform cho armature được hỗ trợ, nhưng nó không ảnh hưởng đến vị trí pose, đường cong animation hay constraint. Nên áp transform trước khi rigging và làm animation.

Cảnh báo

Object Point Cloud 3D Gaussian Splat

Việc áp transform cho object Point Cloud chỉ ảnh hưởng đến vị trí các điểm và không sửa các thuộc tính 3D Gaussian Splat cho scale, góc quay và harmonic cầu.

Quan trọng

Khi áp transform cho một object dùng chung Object Data với object khác, dữ liệu trước tiên phải được chuyển thành Single User. Blender sẽ hỏi bạn xác nhận thao tác này.

Tùy chọn¶

Location

Áp (đặt) vị trí của vùng chọn. Điều này khiến Blender coi vị trí hiện tại tương đương với 0 trên từng mặt phẳng, tức vùng chọn sẽ không di chuyển, vị trí hiện tại sẽ được coi là "vị trí mặc định". Origin của object sẽ được đặt đúng vào (0, 0, 0) (nơi các đường trục màu giao nhau trong từng khung nhìn).

Rotation

Áp (đặt) góc quay của vùng chọn. Điều này khiến Blender coi góc quay hiện tại tương đương với 0 độ trên từng mặt phẳng, tức vùng chọn sẽ không bị xoay, góc quay hiện tại sẽ được coi là "góc quay mặc định".

Scale

Áp (đặt) scale của vùng chọn. Điều này khiến Blender coi scale hiện tại tương đương với 1 trên từng mặt phẳng, tức vùng chọn sẽ không bị scale, scale hiện tại sẽ được coi là "scale mặc định".

Rotation & Scale

Áp (đặt) góc quay và scale của vùng chọn. Thực hiện đồng thời hai phép áp nói trên.

Apply Properties

Sửa các thuộc tính như bán kính vertex của curve, cỡ chữ và bone envelope theo phép biến đổi được áp. (Thấy trong panel Adjust Last Operation)

Corrective Flip Normals

Đảo hướng normal của bề mặt khi áp scale âm. Điều này ngăn hiện tượng shading bị đảo có thể xảy ra khi object có scale âm.

Transforms to Deltas¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply ‣ Location / Rotation / Scale to Deltas

Chuyển các transform chính của object (Location, Rotation, Scale) thành Delta Transforms. Mọi delta transform sẵn có sẽ được cộng vào giá trị mới.

Điều này cho phép bạn "bake" các transform hiện tại vào các kênh delta, trong khi các kênh transform chính được giải phóng cho việc chỉnh sửa hoặc tạo keyframe mới.

Các tùy chọn khả dụng:

  • Location to Deltas -- Chuyển vị trí của object thành Delta Location.

  • Rotation to Deltas -- Chuyển góc quay của object thành Delta Rotation.

  • Scale to Deltas -- Chuyển scale của object thành Delta Scale.

  • All Transforms to Deltas -- Chuyển cả ba cùng lúc.

Tùy chọn¶

Reset Values

Xóa các giá trị transform chính sau khi chuyển sang delta.

Xóa các giá trị transform chính sau khi đã chuyển chúng sang delta. Khi bật, Location, Rotation và Scale chính của object được đặt lại (ví dụ về 0 cho vị trí/góc quay và 1 cho scale), trong khi hình thức vẫn không đổi vì các delta giờ chứa các giá trị trước đó.

Animated Transform to Deltas¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply ‣ Animated Transform to Deltas

Chuyển các keyframe animation sẵn có từ các transform chính của object (Location, Rotation, Scale) thành Delta Transforms.

Nghĩa là dữ liệu animation được chuyển từ các kênh transform chính sang các kênh delta tương ứng, để các transform chính giữ nguyên giá trị hiện tại.

Visual Transform¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply ‣ Visual Transform

Áp kết quả của các constraint cho từng object được chọn vào chính phép biến đổi của object đó. Điều này khiến các object giữ vị trí, góc quay và scale ngay cả khi constraint của chúng bị tắt hoặc bị xóa.

Visual Geometry as Mesh¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply ‣ Visual Geometry to Mesh

Áp trạng thái thị giác của tất cả object được chọn (modifier, shape key, hook, v.v.) vào dữ liệu object. Đây là cách để đóng băng toàn bộ dữ liệu object thành các mesh tĩnh, đồng thời chuyển các kiểu không phải mesh sang mesh.

Để biết chi tiết, xem Convert cho mesh.

Visual Geometry to Objects¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply ‣ Visual Geometry to Objects

Tạo object mới từ hình học đã được tính toán của object đang hoạt động, bao gồm hiệu ứng của mọi modifier, constraint và instancing.

Toán tử này tương tự Make Instances Real, nhưng có một số điểm khác biệt chính:

  • Hình học được instance không được thực thể hóa. Thay vào đó, dữ liệu dùng chung được giữ nguyên giữa các object cùng dùng nó.

  • Object gốc không bị xóa hay sửa đổi, tránh làm gián đoạn ngoài ý muốn các quan hệ với object khác.

  • Cấu trúc phân cấp instancing được giữ lại bằng cách tạo các object và collection mới phản ánh đúng cấu trúc đã tính toán.

Toán tử này hữu ích để trích xuất kết quả hiển thị của geometry nodes, modifier hoặc các thiết lập instancing mà không sửa đổi vĩnh viễn cấu trúc scene gốc.

Ghi chú

Các thuộc tính instance (ví dụ dữ liệu tùy chỉnh cho từng instance) hiện chưa được giữ lại.

Make Instances Real¶

Tham khảo

Mode:

Object Mode

Menu:

Object ‣ Apply ‣ Make Instances Real

Make Instances Real tạo một object mới cho mỗi instance do các object được chọn tạo ra, đồng thời xóa mọi instancing trực tiếp khỏi chúng.

Cuối cùng, mỗi instance trở thành một object thực.

Cảnh báo

Cách này áp dụng cho cả instancing trực tiếp (từ vertex hoặc face...) lẫn gián tiếp (từ particle system...). Nếu bạn có hàng chục nghìn instance (chẳng hạn từ particle), thao tác này có thể làm Blender chậm đi đáng kể, vì Blender không phải lúc nào cũng xử lý tốt một lượng object lớn như vậy trong scene.

Tùy chọn¶

Theo mặc định, object mới sẽ được thêm vào cùng collection với collection chứa instancer của chúng, mà không giữ bất kỳ quan hệ phân cấp nào. Hành vi này có thể được thay đổi bằng các tùy chọn sau.

Parent

Nếu Keep Hierarchy không được bật, toàn bộ object được tạo sẽ lấy instancer cũ làm cha.

Nếu không, toàn bộ object được tạo mà chưa được gán cha sẽ lấy instancer tương ứng của chúng, hoặc bản sao mới tương ứng của nó, làm cha (điều này quan trọng trong trường hợp instancing đệ quy, xem ghi chú bên dưới).

Keep Hierarchy

Giữ lại các cấu trúc phân cấp nội tại (tức quan hệ cha-con) trong các object mới được tạo.

Mẹo

Thường thì để có một cấu trúc phân cấp mới gần giống nhất với cấu trúc instancing ban đầu, bạn sẽ muốn bật cả hai tùy chọn này.

Ghi chú

Việc giữ lại các quan hệ trong trường hợp instancing đệ quy (instancer instance lên các object instancer khác, v.v.) hiện chỉ được hỗ trợ ở mức độ nhất định.

Các trường hợp đơn giản (như một empty instance một collection chứa instance của vài collection khác) thường hoạt động tốt, nhưng các trường hợp phức tạp hơn sẽ không tái hiện đầy đủ toàn bộ cấu trúc phân cấp instancing.
