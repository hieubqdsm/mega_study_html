Transform¶

Tham khảo

Mode:

Object Mode

Panel:

Properties ‣ Object Properties ‣ Transform

Panel:

3D Viewport ‣ Sidebar ‣ Transform

Panel Transform trong vùng Sidebar cho phép bạn xem và điều khiển bằng tay/bằng số vị trí, hướng xoay cùng các thuộc tính khác của một object, trong Object Mode. Mỗi object lưu trữ các giá trị vị trí, hướng và scale của mình. Các giá trị này có thể cần được thao tác bằng số, đặt lại, hoặc áp dụng. Trong Edit Mode, panel này chủ yếu cho phép bạn nhập tọa độ chính xác cho một vertex, hoặc vị trí trung vị cho một nhóm vertex (bao gồm cả edge/face). Vì mỗi loại object có một tập tùy chọn khác nhau trong panel Transform ở Edit Mode, hãy xem phần mô tả tương ứng trong chương Modeling.

Dùng panel này để chỉnh sửa hoặc hiển thị các thuộc tính transform của object như vị trí, hướng xoay và/hoặc scale. Các trường này thay đổi origin của object và sau đó ảnh hưởng đến hình dạng của toàn bộ vertex và face của nó.

Location

Vị trí origin của object trong tọa độ cục bộ.

Rotation

Hướng cục bộ của object, tương đối so với các trục toàn cục và origin của chính nó.

Rotation Mode

Phương pháp tính phép xoay; thông tin bổ sung có thể được tìm thấy trong phụ lục của tài liệu.

Việc đổi chế độ xoay không chuyển đổi animation hiện có. Để giữ nguyên chuyển động đã animation khi chuyển đổi chế độ xoay, hãy dùng operator Convert Rotation Mode.

Euler:

Các tay cầm gizmo được thẳng hàng theo trục Euler, cho phép bạn thấy các trục XYZ rời rạc nằm dưới phép xoay Euler, cũng như hiện tượng Gimbal Lock có thể xảy ra.

Axis Angle:

Tọa độ X, Y và Z xác định một điểm tương đối với origin của object. Điểm này cùng với origin xác định một trục, và giá trị W xác định góc xoay quanh trục đó.

Quaternion:

X, Y, Z và W tương ứng với các thành phần của Quaternion.

Scale

Tỉ lệ tương đối của object theo trục cục bộ (ví dụ: giá trị Scale X thể hiện tỉ lệ theo trục X cục bộ). Mỗi object (cube, sphere, v.v.) khi được tạo đều có scale bằng một đơn vị theo mỗi hướng cục bộ. Để làm object lớn hơn hay nhỏ hơn, bạn scale nó theo trục mong muốn.

Dimensions

Kích thước bounding box của object (thẳng hàng với các trục cục bộ -- hãy tưởng tượng một cái thùng giấy vừa đủ để chứa object).

Khoá thuộc tính Transform

Khi công tắc bị khoá, giá trị biến đổi tương ứng không thể bị thay đổi trong bất kỳ thao tác tương tác nào. Nhưng giá trị vẫn có thể được thay đổi bằng các thao tác phi tương tác, như chỉnh sửa trường số tương ứng hoặc dùng Python.

Ví dụ, nếu bạn khoá thuộc tính Location X thì bạn không thể dùng gizmo 3D để di chuyển object dọc theo trục X toàn cục. Nhưng bạn vẫn có thể di chuyển object bằng trường số Location X. Hãy coi tính năng khoá như một ràng buộc cứng chỉ có thể thay đổi từ panel.

Để khoá một thuộc tính, nhấp vào biểu tượng ổ khoá cạnh nút. Nút được mở khoá nếu biểu tượng là ổ khoá đang mở, và bị khoá nếu biểu tượng là ổ khoá đang đóng.

Delta Transforms¶

Tham khảo

Mode:

Object Mode

Panel:

Properties ‣ Object Properties ‣ Transform ‣ Delta Transforms

Delta Transforms đơn giản là các phép biến đổi được áp dụng lên trên các transform đã mô tả ở trên. Delta Transforms đặc biệt hữu ích trong animation. Ví dụ, bạn có thể animation một object bằng các transform chính rồi di chuyển object bằng Delta Transforms.

Parent Inverse Transform¶

Tham khảo

Mode:

Object Mode

Panel:

Properties ‣ Object Properties ‣ Transform ‣ Parent Inverse

Ngữ cảnh:

Khả dụng khi object được chọn có object cha.

Transform Parent Inverse xác định không gian cục bộ của object con bị dịch chuyển tương đối với cha như thế nào. Nó đảm bảo rằng khi quan hệ parent được tạo, object con giữ nguyên vị trí thế giới hiện tại, mặc dù lúc này nó kế thừa transform từ object cha.

Ma trận được hiển thị dưới dạng phân tách thành các giá trị Location, Rotation và Scale. Chúng thể hiện độ dịch cần thiết để duy trì vị trí của object con tương đối với object cha. Các giá trị này chỉ đọc và được hiển thị chỉ nhằm mục đích kiểm tra.

Rotation Mode quyết định thành phần xoay được hiển thị như thế nào, và có thể được chuyển đổi giữa các hệ như XYZ Euler, Axis Angle hoặc Quaternion. Cách hoạt động giống hệt bộ chọn Rotation Mode dùng trong panel transform chính.

Clear Parent Inverse Transform¶

Xóa ma trận Parent Inverse khỏi các object đã chọn. Khi ma trận rỗng, các thuộc tính vị trí, hướng xoay và scale của object con được diễn giải trực tiếp trong không gian tọa độ của object cha.

Điều này thực chất làm cho transform của object con trở nên tương đối với origin của object cha, có thể khiến object dịch chuyển trong không gian thế giới.

Xem Clear Parent để biết các phương pháp bổ sung nhằm xóa hoặc quản lý quan hệ cha-con.
