Vertices¶

Tham khảo

Mode:

Object Mode

Panel:

Properties ‣ Object Properties ‣ Instancing

Instance Vertices cho phép bạn nhân bản các object con tại vị trí của mọi vertex của object cha.

Ghi chú

Vị trí Object Origin tương đối của object cha và object con quyết định độ dịch của geometry được instance so với vertex của object cha.

Align to Vertex Normal

Xoay tất cả object được instance theo vertex normal tương ứng của mesh cha.

Để đổi trục hướng của các object được instance, chọn object con và thay đổi Tracking Axis.

Thực tế có hai hướng tiếp cận khi mô hình hóa bằng vertex instance. Chúng có thể được dùng như một công cụ sắp đặt, cho phép bạn mô hình hóa sự sắp xếp hình học của các object (ví dụ: các cột của đền Hy Lạp, các cây trong khu vườn, các bàn ghế trong lớp học). Object có thể thuộc bất kỳ loại object nào mà Blender hỗ trợ. Hướng thứ hai là dùng chúng để mô hình hóa một object bắt đầu từ một bộ phận đơn lẻ của nó (ví dụ: các gai trên một chùy, các gai của cầu gai, các viên gạch trên tường, các cánh hoa trong một bông hoa).

Ghi chú

Tải file blend ví dụ

Bạn có thể tải một file chứa các ví dụ được mô tả trong trang này. Trong file blend này, ví dụ đầu tiên, một con khỉ được gán làm con của một đường tròn, nằm ở layer 1; còn một xúc tu được gán làm con của một icosphere nằm ở layer 2.

Cách dùng¶

Vertex instance với vai trò công cụ sắp đặt¶

Tất cả những gì bạn cần là một object cơ sở (ví dụ: cái cây hay cây cột) và một mesh khuôn mẫu có các vertex đi theo khuôn mẫu bạn hình dung. Trong phần này, chúng ta sẽ dùng một scene đơn giản cho phần tiếp theo. Chúng ta sẽ dùng một đầu khỉ đặt tại gốc của hệ tọa độ làm object cơ sở, và một đường tròn tại cùng vị trí đó làm mesh cha.

Đầu tiên, trong Object Mode, chọn object cơ sở rồi Shift-LMB để thêm đường tròn vào vùng chọn (thứ tự rất quan trọng ở đây), sau đó dùng Ctrl-P hoặc Object ‣ Parent ‣ Object để gán object cơ sở làm con của đường tròn. Giờ đây, đường tròn là cha của con khỉ; nếu bạn di chuyển đường tròn, con khỉ sẽ đi theo.

Khi chỉ chọn đường tròn, bật Instancing Vertices; một đầu khỉ sẽ được đặt tại mỗi vertex của đường tròn.

Đầu khỉ gốc ở giữa và mesh cha vẫn được hiển thị trong 3D Viewport nhưng sẽ không được render. Nếu vị trí và hướng xoay của đầu khỉ lạ lùng, bạn có thể cần xóa hướng xoay Alt-R, scale Alt-S, vị trí Alt-G, và origin Object ‣ Clear ‣ Origin.

Sắp xếp lại¶

Nếu bây giờ bạn chọn object cơ sở và chỉnh sửa nó trong Object Mode hoặc Edit Mode, mọi thay đổi cũng sẽ ảnh hưởng đến hình dạng của tất cả object được instance. Bạn cũng có thể chọn mesh cha để chỉnh sửa cách sắp xếp các instance; thêm vertex cũng sẽ thêm nhiều object cơ sở hơn.

Lưu ý rằng các object cơ sở sẽ kế thừa các thay đổi thực hiện trên mesh cha trong Object Mode, nhưng không kế thừa trong Edit Mode. Vì vậy, phóng to đường tròn trong Object Mode sẽ phóng to đầu khỉ, còn phóng to đường tròn trong Edit Mode chỉ làm tăng khoảng cách giữa các object cơ sở.

Orientation¶

Hướng của các object cơ sở có thể được kiểm soát bằng cách bật Align to Vertex Normal trong panel Instancing. Điều này sẽ xoay tất cả object cơ sở theo vertex normal của mesh cha.

Để thay đổi hướng của các object được instance, chọn object cơ sở và thay đổi Tracking Axis.

Kết quả với các hướng khác nhau.¶

Ghi chú

Các trục của một object có thể được hiển thị trong panel Properties ‣ Object Properties ‣ Viewport Display. Để hiển thị vertex normal của mesh cha, vào Edit Mode và bật chế độ trực quan hóa này trong Display & Shading ‣ Viewport Overlays ‣ Normals, nơi bạn cũng có thể đổi kích thước normal hiển thị nếu cần.

Vertex instance với vai trò công cụ mô hình hóa¶

Có thể tạo ra những mô hình rất thú vị bằng Instancing Vertices và một hình khối cơ bản tiêu chuẩn. Trong ví dụ này, một xúc tu đơn giản được tạo bằng cách extrude một cube vài lần. Object xúc tu sau đó được gán làm con của một icosphere. Với Align to Vertex Normal được bật cho mesh cha (icosphere), hướng của object cơ sở (xúc tu) được điều chỉnh theo vertex normal của mesh cha (trong trường hợp này, xúc tu được xoay -90° quanh trục X trong Edit Mode).

Như ở ví dụ trước, hình dạng và tỉ lệ của toàn bộ bố cục giờ có thể được tinh chỉnh.

Để biến toàn bộ geometry được instance thành object thật, chọn icosphere và dùng Make Instances Real. Để gộp icosphere và xúc tu thành một object duy nhất, đảm bảo tất cả đều được chọn rồi vào Object ‣ Join, Ctrl-J.
