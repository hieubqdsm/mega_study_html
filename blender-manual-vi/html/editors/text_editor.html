Text Editor¶

Editor này có thể dùng để viết script Python, các shader dựa trên script như OSL và GLSL, hay đơn giản là ghi chú dạng văn bản thuần. Để mở nó, bạn có thể chuyển sang workspace Scripting hoặc nhấn Shift-F11 để thay thế editor hiện tại.

Header¶

Text editor vừa mở còn trống, với một header rất đơn giản. Sẽ có thêm nhiều tùy chọn hơn khi một file văn bản được tạo hoặc mở.

Editor Type

Nút chọn editor chuẩn.

Menus

Các menu của editor.

Resolve Conflict

Giải quyết xung đột file khi một file văn bản bên ngoài được cập nhật từ chương trình khác.

Reload from Disk

Mở lại file từ ổ đĩa, ghi đè lên mọi thay đổi cục bộ.

Make Text Internal

Chuyển data-block văn bản bên ngoài thành data-block nội bộ.

Ignore

Ẩn thông báo cảnh báo cho đến khi file văn bản bên ngoài lại bị chỉnh sửa từ bên ngoài.

Text

Một menu data-block để chọn văn bản hoặc tạo văn bản mới. Sau đó header sẽ thay đổi.

Run Script (biểu tượng play)

Thực thi văn bản như một script Python Alt-P. Xem Template Menu.

Show

Các công tắc cho số dòng, ngắt dòng và tô sáng cú pháp.

Script Node Update (biểu tượng làm mới)

Khi một file OSL được mở, chức năng này cập nhật node Shader Script với các tùy chọn và socket mới từ script.

View Menu¶

Sidebar Ctrl-T

Hiện hoặc ẩn Sidebar.

Line Numbers

Hiển thị số dòng của file văn bản ở bên trái Main View.

Word Wrap

Ngắt những từ không vừa với khoảng ngang bằng cách đẩy chúng sang một "dòng giả" mới.

Syntax Highlight

Tô màu, trong Main View, các từ đặc biệt được dùng trong ngôn ngữ lập trình Python.

Highlight Line

Nhấn mạnh dòng đang hoạt động bằng cách thay đổi màu nền.

Zoom In/Out

Tăng/giảm cỡ chữ của văn bản trong vùng xem chính.

Navigation
Top Ctrl-Home

Di chuyển vùng xem và con trỏ về đầu file văn bản.

Bottom Ctrl-End

Di chuyển vùng xem và con trỏ về cuối file văn bản.

Line Begin Home

Di chuyển con trỏ về đầu dòng hiện tại.

Line End End

Di chuyển con trỏ về cuối dòng hiện tại.

Previous Line Up

Di chuyển con trỏ đến cùng vị trí trên dòng nằm phía trên dòng hiện tại.

Next Line Down

Di chuyển con trỏ đến cùng vị trí trên dòng nằm phía dưới dòng hiện tại.

Previous Word Ctrl-Left

Di chuyển con trỏ về đầu của từ trước đó. Nếu con trỏ đang ở giữa một từ, con trỏ sẽ được đưa về đầu của từ hiện tại.

Next Word Ctrl-Right

Di chuyển con trỏ về cuối của từ kế tiếp. Nếu con trỏ đang ở giữa một từ, con trỏ sẽ được đưa về cuối của từ hiện tại.

Text Menu¶

New Alt-N

Tạo một data-block văn bản mới.

Open Alt-O.

Tải một file văn bản bên ngoài được chọn qua File Browser.

Reload Alt-R

Mở lại (tải lại) buffer hiện tại (mọi chỉnh sửa chưa lưu sẽ bị mất).

Edit Externally

Chỉnh sửa file văn bản trong trình soạn thảo văn bản bên ngoài. Trình soạn thảo bên ngoài có thể được cấu hình trong User Preferences.

Save Alt-S

Lưu một file đã mở.

Save As Shift-Ctrl-Alt-S.

Lưu văn bản thành một file mới. Một File Browser sẽ được mở để chọn thư mục lưu file, đồng thời đặt tên và phần mở rộng cho file.

Register

Chạy data-block văn bản như một script Python khi tải blend-file. Đọc thêm về việc đăng ký module Python trong tài liệu API.

Live Edit

Chạy lại script Python mỗi lần bạn thay đổi.

Run Script Alt-P

Thực thi văn bản như một script Python. Xem Running Scripts để biết thêm thông tin.

Edit Menu¶

Undo/Redo

Xem Undo & Redo.

Cut Ctrl-X

Cắt đoạn văn bản được đánh dấu vào clipboard.

Copy Ctrl-C

Sao chép đoạn văn bản được đánh dấu vào clipboard.

Paste Ctrl-V

Dán văn bản từ clipboard tại vị trí con trỏ trong Text editor.

Duplicate Line Ctrl-D

Nhân đôi dòng hiện tại.

Move Line(s) Up Shift-Ctrl-Up

Đổi chỗ dòng hiện tại/được chọn với dòng phía trên.

Move Line(s) Down Shift-Ctrl-Down

Đổi chỗ dòng hiện tại/được chọn với dòng phía dưới.

Find & Replace Ctrl-F

Hiển thị panel Find & Replace trong Sidebar.

Find & Set Selection Ctrl-G

Tìm lần xuất hiện kế tiếp của đoạn văn bản được chọn.

Jump To Ctrl-J

Hiển thị một pop-up cho phép bạn chọn số dòng để di chuyển con trỏ tới đó.

Text Auto Complete Tab

Hiển thị danh sách có thể chọn gồm các từ đã dùng trong văn bản.

Text to 3D Object

Chuyển file văn bản thành một Text Object theo kiểu One Object hoặc One Object Per Line.

Select Menu¶

All Ctrl-A

Chọn toàn bộ file văn bản.

Line Shift-Ctrl-A

Chọn toàn bộ dòng hiện tại.

Word double-click LMB

Chọn toàn bộ từ hiện tại.

Top Shift-Ctrl-Home

Chọn mọi thứ phía trên con trỏ.

Bottom Shift-Ctrl-End

Chọn mọi thứ phía dưới con trỏ.

Line Begin Shift-Home

Chọn mọi thứ giữa đầu dòng hiện tại và con trỏ.

Line End Shift-End

Chọn mọi thứ giữa con trỏ và cuối dòng hiện tại.

Previous Line Shift-Up

Chọn mọi thứ giữa con trỏ và vị trí con trỏ cách một dòng phía trên.

Next Line Shift-Down

Chọn mọi thứ giữa con trỏ và vị trí con trỏ cách một dòng phía dưới.

Previous Word Shift-Ctrl-Left

Chọn mọi thứ giữa con trỏ và đầu của từ trước đó. Nếu con trỏ đang ở giữa một từ, chọn mọi thứ cho đến đầu của từ hiện tại.

Next Word Shift-Ctrl-Right

Chọn mọi thứ giữa con trỏ và cuối của từ kế tiếp. Nếu con trỏ đang ở giữa một từ, chọn mọi thứ cho đến cuối của từ hiện tại.

Format Menu¶

Indent Tab

Chèn một ký tự tab tại vị trí con trỏ.

Unindent Shift-Tab.

Bỏ thụt đầu dòng của vùng chọn.

Toggle Comments Ctrl-Slash.

Bật/tắt việc các dòng được chọn là chú thích Python. Nếu không có dòng nào được chọn, dòng hiện tại sẽ bị bật/tắt.

Convert Whitespace

Chuyển các ký tự thụt đầu dòng thành To Spaces hoặc To Tabs.

Template Menu¶

Chứa một số template cho cả script Python lẫn Open Shading Language.

Main View¶

Gõ bàn phím sẽ tạo văn bản trong buffer văn bản.

Như thường lệ, nhấn, kéo rồi thả LMB sẽ chọn văn bản. Nhấn RMB sẽ mở menu ngữ cảnh.

Mẹo

Text editor cũng rất tiện khi bạn muốn chia sẻ blend-file với người khác: bạn có thể để lại một ghi chú giải thích file được tổ chức như thế nào. Hãy nhớ để editor hiển thị rõ khi lưu để họ nhìn thấy nó!

Sidebar¶

Find & Replace¶

Find Text Ctrl-F

Tìm các lần xuất hiện của một đoạn văn bản nằm sau con trỏ. Dùng biểu tượng eyedropper sẽ tìm đoạn văn bản đang được chọn và đặt vùng chọn vào kết quả khớp. Find Next tìm lần xuất hiện kế tiếp của đoạn văn bản.

Replace Text Ctrl-H

Tìm đoạn văn bản được chỉ định trong Find Text và thay thế nó bằng văn bản mới. Dùng biểu tượng eyedropper sẽ đặt đoạn văn bản đang chọn làm văn bản thay thế. Replace tìm kết quả khớp kế tiếp và thay thế nó. Replace All tìm kết quả khớp và thay thế mọi lần xuất hiện của nó bằng văn bản mới.

Case

Phân biệt chữ hoa và chữ thường khi tìm kiếm.

Wrap

Khi đến cuối file thì tìm lại từ đầu file.

All

Tìm trong tất cả data-block văn bản thay vì chỉ data-block đang hoạt động.

Properties¶

Margin

Hiển thị một đường lề dọc để giúp giữ các dòng văn bản ở độ dài hợp lý. Vị trí của đường lề này được chỉ định bởi Margin Column.

Font Size Ctrl-WheelUp

Cỡ chữ dùng để hiển thị văn bản.

Tab Width

Số khoảng cách ký tự dùng để hiển thị ký tự tab.

Indentation

Dùng Tabs hay Spaces cho việc thụt đầu dòng.

Footer¶

Footer của Text editor hiển thị văn bản được lưu nội bộ hay bên ngoài, và liệu có thay đổi chưa lưu đối với file bên ngoài hay không. Với file bên ngoài, vùng này còn hiển thị đường dẫn đến file văn bản.

Cách dùng¶

Running Scripts¶

Phím tắt đáng chú ý nhất là Alt-P, vốn thực thi văn bản hiện tại như một script Python. Bạn có thể truy cập không chỉ các module Python chuẩn mà còn cả một loạt module riêng của Blender; xem Scripting & Mở rộng Blender.
